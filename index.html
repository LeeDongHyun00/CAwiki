CAWIKI · COMPUTER ARCHITECTURE

작동 순서로 배우는
컴퓨터 아키텍처

일상의 동작 하나가 하드웨어를 어떤 경로로 통과하는지, 아키텍처별로 한 단계씩 따라갑니다. 스크롤·방향키·클릭 — 어떤 입력이든 정확히 한 단계만 진행되고, 애니메이션이 끝나기 전에는 건너뛸 수 없습니다.

ARCH 01 · POWER ON

부팅 — 전원에서 로그인까지

PSU → UEFI 펌웨어 → POST → 부트로더 → 커널. 전원 버튼 하나로 시작되는 일곱 부품의 릴레이.

8단계 · 메인보드 구성 ARCH 02 · INPUT TO PHOTON

게임 — 클릭에서 픽셀까지

입력 장치 → CPU 게임 루프 → GPU 렌더링 → 스캔아웃 → 모니터. 초당 수백 번 반복되는 파이프라인.

8단계 · 파이프라인 구성 ARCH 03 · ROUND TRIP

검색 — 집에서 데이터센터까지

DNS → TCP·TLS → 공유기 → ISP → 해저케이블 → 로드밸런서 → 검색 서버. 지구 크기의 왕복.

8단계 · 네트워크 지형 구성 ARCH 04 · STORAGE READ PATH

파일 열기 — 셀에서 화면까지

파일시스템 → NVMe → DMA → RAM 페이지 캐시 → CPU 캐시 계층 → 화면. SSD가 빠른 이유.
