# 오디오 서브시스템 (코덱·앰프·스피커·마이크)
*Audio Subsystem (Codec, Amplifier, Speaker, Microphone)*

> 숫자로 저장된 소리(PCM)를 진짜 공기의 떨림으로 바꾸고(재생), 반대로 공기의 떨림을 숫자로 붙잡는(녹음) 컴퓨터의 아날로그↔디지털 변환 경로 전체.

**분류**: 입출력

---

## 🧭 한마디로, 무슨 일을 하나
오디오 서브시스템은 컴퓨터의 세계(0과 1의 숫자)와 사람의 세계(귀로 듣는 공기 진동) 사이를 잇는 양방향 번역기다. 재생 방향에서는 메모리에 있는 PCM 샘플을 DAC로 아날로그 전압으로 되돌리고, 파워 앰프로 세기를 키워 스피커·이어폰의 진동판을 흔든다. 녹음 방향에서는 마이크가 잡은 미세한 전압을 프리앰프로 키우고 ADC로 다시 숫자로 만든다. CPU·GPU·DSP가 '무엇을 들려줄지'를 계산한다면, 이 서브시스템은 그 결과를 실제로 귀에 도달시키거나 사람의 목소리를 시스템 안으로 들여보내는 마지막·첫 관문이다. 순수 디지털 파트(버퍼·DMA·필터·변조)와, 잡음·간섭에 민감한 아날로그 파트(변환·증폭·트랜스듀서)가 한 경로 안에 공존하는 점이 이 서브시스템의 특징이다.

## ⚙️ 작동 방식

**1. 디지털 오디오 준비와 버퍼링 — 소프트웨어가 소리를 '숫자 줄'로 넘긴다**

재생할 소리는 이미 PCM(Pulse Code Modulation, 펄스 부호 변조) 샘플의 나열이다. 예컨대 48 kHz·16비트·스테레오면 1초에 좌우 각 48,000개의 16비트 정수(총 96,000개)가 필요하다. OS 오디오 스택(Windows WASAPI, macOS/iOS CoreAudio, Linux ALSA/PipeWire, Android AAudio 등)이 이 샘플을 링 버퍼(ring buffer)에 채워 두면, DMA(Direct Memory Access) 엔진이 CPU를 거의 깨우지 않고 일정 간격으로 코덱에 실어 보낸다. '왜 버퍼가 필요한가' — CPU는 다른 일로 바빠 샘플 공급이 들쭉날쭉하지만, 소리는 한 샘플도 끊기면 안 되므로 물통에 물을 미리 받아 두듯 몇 ms치를 쌓아 두고 일정하게 흘려보낸다. 이 버퍼 크기가 곧 지연(latency)의 원천이다.

**2. 오버샘플링과 디지털 보간 필터 — DAC가 계단을 잘게 쪼갤 준비를 한다**

현대 오디오 DAC는 곧바로 아날로그로 바꾸지 않고, 먼저 입력 샘플레이트를 수십~수백 배로 끌어올리는 오버샘플링(oversampling)을 한다(예: 64×, 128×, 256×). 원래 샘플들 사이에 디지털 보간(interpolation) 필터로 중간값을 채워 넣어 데이터 흐름을 아주 촘촘하게 만든다. '왜' — 나중에 필요한 아날로그 저역통과(재구성) 필터를 아주 완만하고 값싼 것으로 써도 되게 하고(가파른 필터는 위상 왜곡·비용 부담이 큼), 양자화 잡음을 훨씬 넓은 주파수로 퍼뜨려 가청대역(약 20 Hz–20 kHz)을 깨끗하게 비우기 위한 사전 작업이다.

**3. 델타시그마 변조 — 여러 비트를 초고속 저비트 '점멸'로 바꾼다**

오버샘플된 신호를 델타시그마(ΔΣ) 변조기가 아주 낮은 비트수의 초고속 펄스열로 바꾼다. 순수 1비트 변조는 DSD·SACD와 일부 설계의 특징이고, 현대 고성능 오디오 DAC는 흔히 다중비트(다레벨, 대략 3~6비트급) 델타시그마를 써서 대역 밖 잡음과 아이들 톤(idle tone)을 줄인다. 비트수와 무관하게 핵심은 노이즈 셰이핑(noise shaping): 피드백 루프가 매 순간의 오차(양자화 잡음)를 적분·되먹여 가청대역 밖 고주파로 밀어낸다. '왜 몇 비트로도 고음질인가' — 순간값은 거칠지만, 초당 수백만 번 점멸하는 펄스의 '밀도'가 원 파형의 크기를 표현한다. 흑백 신문의 하프톤 점이 멀리서 보면 회색조가 되는 것과 같은 원리다. 그래서 '저비트=저해상도'가 아니다.

**4. 아날로그 재구성 — 저역통과 필터가 펄스열을 부드러운 파형으로 되돌린다**

델타시그마의 고속 펄스열을 아날로그 저역통과 필터(LPF, 재구성 필터)로 매끈하게 평균 내면, 고주파로 밀려나 있던 양자화 잡음이 잘려 나가고 원래의 아날로그 음파 전압이 복원된다. 코덱 안의 헤드폰 앰프나 라인 아웃 단은 이 신호를 이어폰(수십 Ω)이나 라인 레벨로 내보낸다. '왜 필터가 마지막에 오나' — 계단·펄스 모양의 이산 신호를 사람이 들을 연속 파형으로 만드는 '재구성(reconstruction)'이 이 필터의 일이기 때문이다. 이 아날로그 단은 깨끗한 전원(LDO·차지펌프)과 접지 설계에 민감하다.

**5. 파워 증폭 — D클래스 앰프가 스피커를 흔들 만큼 힘을 키운다**

DAC가 만든 신호는 전압만 있고 전류(힘)가 약해 큰 스피커를 못 민다. 파워 앰프가 세기를 키운다. 노트북·TV·스마트폰·블루투스 스피커는 대부분 D클래스(Class-D) 스위칭 앰프를 쓴다: 입력 파형을 수백 kHz의 PWM(Pulse Width Modulation, 펄스 폭 변조)으로 바꾸고, 출력 MOSFET을 완전히 켜거나 끄기만 반복한 뒤, LC(코일·콘덴서) 필터로 평균 내 원 파형을 복원한다. '왜 D클래스인가' — 트랜지스터가 항상 반쯤 켜져 열로 낭비하는 A/AB급과 달리, 스위치가 완전 온·오프만 하니 효율이 대략 85~95%로 높아 발열·배터리에 유리하다. 모바일 소형 스피커용 '스마트 앰프'는 여기에 보이스코일의 전류·전압(IV)을 실시간 감지해 코일 온도·변위를 추정하고, 손상 없이 최대한 크고 낮은 음까지 밀어붙인다(스피커 보호·부스트). D클래스는 '디지털 앰프'가 아니라 스위칭 방식 아날로그 앰프다.

**6. 스피커 변환 — 전기를 다시 공기의 떨림으로 (전기→소리)**

앰프가 보낸 교류 전류가 스피커의 보이스코일(voice coil)에 흐른다. 코일은 영구자석이 만든 자기장 속 좁은 에어갭(air gap) 안에 놓여 있어, 전류 방향·세기에 따라 힘(F=BIL, 전류가 흐르는 도선이 자기장에서 받는 힘)으로 앞뒤로 밀린다. 코일에 붙은 콘·진동판(diaphragm)이 함께 왕복하며 앞의 공기를 밀고 당겨 음파(공기 압력 변화)를 만든다. 스파이더·서라운드(서스펜션)가 코일을 중심에 잡아 두어 제자리로 돌아오게 한다. 우퍼·트위터가 나뉜 멀티웨이 스피커는 크로스오버 회로가 주파수 대역을 갈라 각 드라이버로 보낸다. '왜 소리가 나는가' — 전류 파형이 곧 진동판의 움직임이 되고, 그 움직임이 곧 귀에 닿는 압력 파형이 되기 때문이다.

**7. (역방향) 마이크 캡처와 ADC — 목소리를 숫자로 붙잡는다**

녹음은 반대 순서다. 마이크의 진동판이 음파에 흔들리며 전기 신호를 만든다. 콘덴서·일렉트릿·MEMS 마이크는 진동판과 고정 백플레이트가 이루는 축전기의 간격 변화를 전압 변화로 바꾸므로 바이어스(전원)가 필요하다. 아주 작은 이 신호를 프리앰프(PGA, 가변이득 증폭기)로 키우고, ADC 앞단의 안티에일리어싱 필터로 나이퀴스트 한계를 넘는 성분이 접혀 들어오는 것(에일리어싱)을 막은 뒤, ADC(Analog-to-Digital Converter)가 표본화·양자화해 PCM 숫자로 만든다. ADC도 흔히 델타시그마 방식이라 내부 변조기는 MHz급으로 돌지만 최종 출력 PCM 표본율은 보통 44.1/48 kHz다. 이 숫자열이 DMA로 메모리에 쌓이면, 통화 앱·음성비서·녹음기 소프트웨어가 읽어 처리한다.

## 🧩 주요 부품

| 부품 | 하는 일 |
|---|---|
| **오디오 코덱 칩 (Audio Codec IC, 예: Realtek ALC·Cirrus Logic·ESS Sabre·AKM)** | DAC·ADC·마이크 프리앰프·헤드폰 앰프·믹서·디지털 인터페이스를 하나로 묶은 통합 칩. 메인보드·폰의 '소리 담당' 핵심으로, PCM을 아날로그로 또 그 반대로 변환한다. (파일 압축 포맷인 MP3·AAC '코덱'과는 이름만 같고 다른 것.) |
| **DAC (Digital-to-Analog Converter, 디지털→아날로그 변환기)** | PCM 숫자를 아날로그 전압 파형으로 되돌린다. 대부분 오버샘플링 디지털 필터 + 델타시그마 변조기(다중비트가 흔함) + 아날로그 재구성 필터로 구성된다. (고급기는 R-2R 저항 사다리 방식도 있음.) |
| **ADC (Analog-to-Digital Converter, 아날로그→디지털 변환기)** | 마이크·라인 입력의 아날로그 전압을 안티에일리어싱 필터로 거른 뒤 표본화·양자화해 PCM 숫자로 만든다. 오디오에서는 주로 델타시그마 ADC를 쓴다. |
| **마이크 프리앰프 / PGA (Programmable Gain Amplifier)** | 마이크가 만든 아주 작은 신호를 ADC가 다룰 수 있는 크기로 키우는 가변이득 증폭단. 이득이 너무 크면 클리핑, 너무 작으면 잡음에 묻힌다. |
| **헤드폰/라인 앰프 + 출력 잭 (콤보 TRRS·잭 감지)** | 코덱 출력을 이어폰(수십 Ω)이나 라인 레벨로 내보내는 소형 증폭단과, 그 신호가 나가는 아날로그 잭. 임피던스가 높은 헤드폰을 충분히 울리려면 이 단의 구동력이 중요하다. 콤보(TRRS) 잭은 헤드폰+마이크를 겸하고, 잭 감지(jack detection)로 삽입 여부·타입을 인식해 스피커↔이어폰 경로를 자동 전환한다. |
| **파워 앰프 (Class-D 스위칭 앰프 / 스마트 앰프)** | 스피커를 실제로 구동할 만큼 전류를 키운다. PWM 변조기 + 출력 MOSFET(하프·풀 브리지) + LC 출력 필터로 이뤄지며, 효율이 높아 모바일·소형 스피커에 표준으로 쓰인다. 스마트 앰프는 IV(전류·전압) 피드백으로 코일 온도·변위를 추정해 스피커를 보호하면서 음량·저음을 끌어올린다. |
| **크로스오버 네트워크 (Crossover)** | 멀티웨이 스피커에서 저음은 우퍼, 고음은 트위터로 주파수 대역을 나눠 보내는 필터 회로. 코일·콘덴서로 만든 수동형과, 앰프 앞에서 DSP·능동 필터로 나누는 능동형이 있다. |
| **오디오 클럭 / PLL (수정 발진자 + 위상동기루프)** | MCLK(마스터)·BCLK(비트)·LRCLK/워드클럭 등 변환 타이밍을 만든다. 클럭이 흔들리면(지터) 표본 시점이 어긋나 음질이 나빠진다. 44.1 kHz 계열(22.5792 MHz)과 48 kHz 계열(24.576 MHz)을 위해 보통 두 종류의 기준 클럭을 둔다. |
| **디지털 오디오 인터페이스 (I2S / PDM / SoundWire / HD Audio / USB Audio)** | 코덱과 CPU·SoC(또는 외장 장치) 사이로 오디오 데이터를 나르는 직렬 버스. I2S는 재생용 다중비트 스트림, PDM(Pulse Density Modulation)은 MEMS 마이크의 1비트 스트림, SoundWire는 저전력 다중장치, USB Audio는 외장 DAC 연결에 흔히 쓰인다. |
| **스피커 — 보이스코일 · 영구자석 · 에어갭 · 콘/진동판 · 서스펜션 · 프레임 · 더스트캡** | 보이스코일에 흐르는 전류가 영구자석의 에어갭 자기장 속에서 힘을 받아 왕복하고, 콘·진동판이 공기를 밀어 음파를 만든다. 스파이더·서라운드(서스펜션)가 코일을 중심에 유지하고, 프레임(바스켓)이 전체를 지지, 더스트캡이 에어갭을 보호한다. |
| **마이크 — 콘덴서/일렉트릿(ECM) · MEMS · 다이나믹** | 콘덴서·일렉트릿·MEMS는 진동판과 고정 백플레이트가 가변 축전기를 이뤄 간격 변화를 전압 변화로 바꾼다(바이어스 필요). MEMS는 실리콘 초소형 콘덴서 마이크로 전용 ASIC(증폭·변환, 아날로그 또는 PDM 출력)을 품어 폰·노트북에 들어간다. 다이나믹(무빙코일)은 코일+자석으로 별도 전원 없이 동작한다. |
| **믹서 / 라우팅 / 음성 DSP 블록** | 여러 입력·출력(스피커·이어폰·마이크·HDMI)을 섞고 경로를 정하며, 볼륨·이퀄라이저·에코 제거(AEC)·노이즈 억제·자동 이득(AGC)·능동 소음 제거(ANC)·마이크 어레이 빔포밍 같은 처리를 코덱·SoC·NPU 안에서 수행한다. |
| **아날로그 전원 · 기준전압 (LDO / 차지펌프 / 밴드갭)** | 변환·증폭 단에 깨끗하고 안정된 전압을 공급한다. 스위칭 잡음이 섞인 시스템 전원을 그대로 쓰면 험·잡음이 새어 들어오므로, 저잡음 LDO·차지펌프로 아날로그 레일을 분리하고 기준전압을 만든다. |

## 📚 핵심 개념

| 용어 | 설명 |
|---|---|
| **PCM (Pulse Code Modulation, 펄스 부호 변조)** | 소리를 일정 간격으로 찍은 표본값을 정수로 저장하는 가장 기본적인 디지털 오디오 형식. WAV·CD가 대표적이며, 압축된 MP3·AAC도 재생 직전엔 PCM으로 풀린다. |
| **샘플링레이트 / 나이퀴스트 정리 (Sampling Rate / Nyquist Theorem)** | 1초에 소리를 몇 번 표본화하는가(단위 Hz). 표본화하려는 최고 주파수의 2배보다 크게(초과) 표본화해야 한다 — 정확히 2배에서는 그 성분을 신뢰성 있게 복원할 수 없다. 사람 청각 상한이 약 20 kHz라 CD는 44.1 kHz(나이퀴스트 22.05 kHz, 실사용 상한 약 20 kHz)를 쓴다. |
| **비트뎁스 / 양자화 (Bit Depth / Quantization)** | 각 표본을 몇 비트로 표현하는가. 이론 SNR은 6.02N + 1.76 dB로, 비트가 1개 늘 때마다 약 6 dB 커진다. 16비트=65,536단계≈98 dB(흔히 96 dB로 인용), 24비트≈이론상 약 146 dB(흔히 144 dB). 낮으면 양자화 잡음이 커진다. |
| **델타시그마 변조 (Delta-Sigma / ΔΣ Modulation)** | 신호를 초고속 저비트 펄스열로 바꾸는 방식. 오차를 피드백으로 되먹여(적분) 잡음을 고주파로 밀어낸다(노이즈 셰이핑). 현대 오디오 DAC/ADC의 표준이며, 순수 1비트보다 다중비트(다레벨)가 흔하다. |
| **오버샘플링 · 노이즈 셰이핑 (Oversampling · Noise Shaping)** | 필요한 최소치보다 수십~수백 배 빠르게 처리해 양자화 잡음을 넓게 퍼뜨리고(오버샘플링), 그 잡음을 가청대역 밖으로 몰아내는(노이즈 셰이핑) 기법. 값싼 완만한 필터로 고음질을 얻는 비결. |
| **DAC / ADC (디지털↔아날로그 변환기)** | DAC는 숫자를 전압 파형으로(재생), ADC는 전압 파형을 숫자로(녹음) 바꾼다. 오디오 코덱 칩은 둘을 함께 품는다. |
| **오디오 코덱 (Audio Codec) — 두 가지 뜻 구분** | ① 코덱 칩(coder-decoder IC): DAC+ADC를 통합한 하드웨어. ② 코덱 포맷: MP3·AAC·Opus 같은 압축·부호화 방식. CAwiki에서 '오디오 하드웨어의 코덱'은 ①을 뜻한다. |
| **D클래스 · PWM (Class-D · Pulse Width Modulation)** | 출력 트랜지스터를 완전히 켜고 끄기만 반복(펄스 폭으로 세기 표현)한 뒤 LC 필터로 평균 내 증폭하는 고효율 스위칭 앰프. 디지털 앰프가 아니라 스위칭 방식의 아날로그 증폭이다. 'D'는 A·B·AB·C 다음 알파벳일 뿐 Digital의 약자가 아니다. |
| **I2S · PDM (오디오 직렬 인터페이스)** | I2S(Inter-IC Sound)는 코덱-프로세서 간 다중비트 오디오 전송 표준 버스(BCLK·LRCLK/WS·데이터). PDM(Pulse Density Modulation)은 MEMS 마이크가 내보내는 1비트 밀도 변조 스트림. |
| **DSD (Direct Stream Digital)** | 델타시그마와 직결된 1비트 초고속(예: 2.8/5.6 MHz) 오디오 포맷. SACD의 저장 방식으로, PCM과 달리 노이즈 셰이핑된 1비트 밀도로 파형을 표현한다. |
| **임피던스 · 감도 (Impedance · Sensitivity)** | 임피던스(Ω)는 스피커·헤드폰이 전류에 저항하는 정도(스피커 4~8 Ω, 헤드폰 16~600 Ω). 감도는 스피커는 dB SPL @ 1W/1m(또는 2.83V/1m), 헤드폰은 dB SPL/mW 또는 /V로 표기 — 같은 전력·전압으로 얼마나 크게 우는가. 소리 크기는 와트만이 아니라 감도가 좌우한다. |
| **음성 처리 DSP — 빔포밍 · AEC · ANC · AGC** | 마이크 어레이(2~4개)로 방향을 골라 목소리만 키우는 빔포밍, 스피커 소리가 내 마이크로 되돌아가는 것을 지우는 에코 제거(AEC), 주변 소음을 역위상으로 상쇄하는 능동 소음 제거(ANC), 입력 크기를 자동으로 맞추는 자동 이득(AGC). 화상통화·음성비서·이어폰의 핵심. |
| **지연 · 버퍼 언더런 (Latency · Buffer Underrun)** | 버퍼 크기÷샘플레이트가 한 블록 지연이다(예: 256샘플÷48 kHz≈5.3 ms). 버퍼가 비면(언더런·xrun) '뚝·틱' 잡음이 난다. 지연을 줄이려 버퍼를 작게 하면 언더런 위험이 커진다. |
| **SNR · THD+N · 다이내믹레인지 (음질 지표)** | SNR·다이내믹레인지(dB)는 신호 대 잡음 폭(클수록 조용한 소리까지 표현), THD+N(%)은 원 파형을 얼마나 왜곡 없이 재현하는가. 코덱·앰프 품질을 재는 대표 수치. |

## ⚠️ 흔한 오해

- **오해** — '코덱'은 MP3·AAC 같은 압축 파일 포맷을 뜻한다.
  <br>**교정** — 두 가지가 이름만 같다. 오디오 하드웨어의 '코덱 칩'은 DAC+ADC를 통합한 변환 IC(coder-decoder)이고, MP3·AAC는 데이터 압축·부호화 방식이다. CAwiki 하드웨어 편의 코덱은 칩을 가리킨다.
- **오해** — 샘플레이트·비트뎁스가 높을수록 사람 귀에 항상 더 좋게 들린다.
  <br>**교정** — 44.1/48 kHz·16비트면 이미 인간 청각 범위(약 20 kHz·약 96 dB)를 넉넉히 담는다. 96/192 kHz·24비트의 장점은 주로 제작·편집 여유(헤드룸·처리 마진)이며, 최종 청취에서의 체감 이득은 제한적이다.
- **오해** — 델타시그마 DAC는 1비트라서 16비트 PCM보다 해상도가 낮다.
  <br>**교정** — 순간값만 저비트일 뿐, 초고속 오버샘플링과 노이즈 셰이핑으로 가청대역의 유효 해상도는 오히려 매우 높다. 게다가 현대 DAC는 순수 1비트보다 다중비트 델타시그마가 흔하다. 펄스 '밀도'가 크기를 표현하므로 다중비트 못지않은 음질을 낸다.
- **오해** — D클래스 앰프는 '디지털 앰프'다.
  <br>**교정** — D클래스는 트랜지스터를 스위치처럼 켜고 끄는 스위칭 방식일 뿐, 신호 자체는 아날로그다. 입력이 디지털일 필요도 없다. 'Class-D'의 D는 A·B·AB·C 다음 알파벳 순서이지 Digital의 약자가 아니다.
- **오해** — 스피커와 마이크는 완전히 다른 원리의 장치다.
  <br>**교정** — 다이나믹(무빙코일) 타입은 서로 정반대 동작이다. 코일+자석 스피커에 소리를 넣으면 마이크가 되고, 다이나믹 마이크에 전류를 흘리면 작은 스피커가 된다. 전기↔진동 변환이라는 같은 물리를 방향만 바꿔 쓴다. 다만 콘덴서·일렉트릿·MEMS 마이크는 이렇게 단순히 뒤집어 스피커로 쓸 수 없다.
- **오해** — 자석이 크거나 정격 와트가 높으면 무조건 소리가 크다.
  <br>**교정** — 체감 음량은 감도(dB SPL @ 1W/1m) 지표가 좌우한다. 감도가 낮은 스피커는 같은 전력에서도 조용하다. 와트는 견딜 수 있는 전력의 상한일 뿐 음량과 1:1이 아니다.
- **오해** — 디지털 오디오는 즉시 재생되므로 지연이 없다.
  <br>**교정** — 끊김 방지를 위해 반드시 버퍼에 몇 ms~수십 ms치를 쌓아 두고 내보낸다. 지연은 버퍼 크기÷샘플레이트로 정해지며, 블루투스·무선은 여기에 코덱·전송 지연이 더해져 수백 ms에 이르기도 한다.
- **오해** — 블루투스로 들으면 원본 그대로(무손실) 들린다.
  <br>**교정** — SBC·AAC 등 대부분의 블루투스 코덱은 손실 압축이라 원본과 다르다. 유선·USB나 LDAC·aptX HD 같은 고비트레이트 코덱이 더 원본에 가깝고, 진정한 무손실은 유선·USB 경로에서 얻기 쉽다.

## 💡 비유

DAC의 델타시그마는 '흑백 신문의 하프톤 인쇄'와 같다. 잉크는 검정 아니면 흰색(저비트)뿐이지만, 아주 작은 점들의 촘촘함(밀도)이 멀리서 보면 연속된 회색조로 보인다. 초고속으로 점멸하는 펄스의 '밀도'가 곧 소리의 크기다. / D클래스 앰프의 PWM은 '아주 빠른 조광 스위치(디머)'다. 전구를 반쯤 켜는 대신 완전히 껐다 켰다를 초당 수십만 번 반복하면, 켜져 있는 시간 비율이 평균 밝기가 된다 — 스위치라 열 낭비가 적어 효율이 높다. / 스피커와 마이크는 '종이컵 전화기'의 양쪽 방향이다. 한쪽은 전기를 떨림으로(스피커), 반대쪽은 떨림을 전기로(마이크) 바꾼다.

## 🔗 CAwiki 시나리오에서 만나는 곳

- 소리 재생: 음악·알림음을 누르는 순간 — 메모리의 PCM이 DMA→코덱 DAC→(델타시그마·오버샘플링)→아날로그→D클래스 앰프→스피커 보이스코일까지 흘러 실제 공기 진동이 되는 이 서브시스템의 대표 무대.
- 영상 스트리밍(유튜브·넷플릭스): AAC/Opus로 압축된 사운드트랙이 CPU에서 PCM으로 디코딩된 뒤, 화면(프레임)과 입 모양이 맞도록 오디오·비디오 동기(A/V sync)를 유지하며 DAC로 흘러 스피커로 나간다.
- AI에게 질문(음성 비서): '헤이' 하고 말하면 마이크(콘덴서·MEMS)→프리앰프→ADC로 목소리가 숫자가 되어 시스템에 들어가고(입력), 답변 음성(TTS)은 반대로 DAC→앰프→스피커로 나온다(출력) — 왕복이 한 화면에 다 보이는 시나리오.
- 게임 조작이 화면이 되기까지: 총성·발소리의 방향감(3D positional audio)을 실시간으로 섞어 내보내며, 입력과 소리의 어긋남을 줄이려 오디오 지연(버퍼)을 작게 유지하는 저지연 요구가 두드러진다.
- 화상통화: 마이크 캡처(ADC)와 스피커 재생(DAC)이 동시에 돌아가며, 상대 목소리가 내 마이크로 되돌아가지 않게 에코 제거(AEC)·노이즈 억제·빔포밍 DSP가 코덱·SoC 안에서 작동한다.
- 컴퓨터가 켜지는 과정(부팅): 일부 시스템은 POST 완료·경고를 알리는 시동음·비프로 오디오 경로가 살아 있음을 처음 알린다(내장 버저 또는 코덱 경유).
