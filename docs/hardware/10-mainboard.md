# 메인보드·칩셋(PCH)
*Motherboard & Chipset (Platform Controller Hub)*

> 모든 부품을 물리적으로 꽂아 연결하고, 전원을 정밀하게 나눠주며, CPU에 직결되지 않는 저속·다수 장치를 칩셋(PCH)이 모아 DMI 한 링크로 CPU에 이어주는 컴퓨터의 기반 배선판이다.

**분류**: 기판·버스·전원

---

## 🧭 한마디로, 무슨 일을 하나
메인보드는 스스로 연산하지 않는다. 대신 CPU·RAM·GPU·저장장치·I/O 장치가 서로 전기 신호를 주고받을 길(구리 트레이스)과 꽂을 자리(소켓·슬롯)를 제공하고, PSU의 전원을 각 부품이 요구하는 전압으로 변환해 배분한다. 여기서 칩셋(Intel의 PCH, AMD의 FCH)은 USB·SATA·추가 PCIe·네트워크·오디오처럼 상대적으로 느리고 수가 많은 장치들을 한데 모아 관리하는 I/O 허브 역할을 맡아, 이들을 DMI라는 한 개의 고속 업링크로 CPU에 연결한다. 과거 노스브리지가 담당하던 메모리 컨트롤러·주 PCIe·내장 그래픽은 모두 CPU 안으로 이동했기 때문에, 오늘날 메인보드 위의 대형 칩은 사실상 이 칩셋 하나뿐이다. 또한 RTC 시계 유지, 기준 클럭 생성, 전원 시퀀싱, 신뢰 루트(TPM/fTPM), (노트북의) 임베디드 컨트롤러 같은 상시·관리 기능이 벌어지는 무대이기도 하다.

## ⚙️ 작동 방식

**1. 상시 전원 대기와 전원 버튼 신호 접수**

콘센트에 꽂혀 있거나 배터리가 붙어 있으면, PSU의 대기 전원(+5VSB, 5V standby)이 항상 칩셋 일부·RTC·(노트북)EC에 흐른다. 그래서 컴퓨터가 '꺼진' 상태(soft-off)에서도 전원 버튼·Wake-on-LAN·RTC 알람을 감시할 수 있다. 사용자가 전원 버튼을 누르면 그 신호를 칩셋의 전원관리부(또는 노트북의 EC)가 받아 부팅 절차를 시작시킨다.

**2. 전원 시퀀싱과 VRM의 강압, Power Good**

칩셋/EC가 PSU에 'PS_ON#'을 보내 주 전원을 켜고, 각 전압 레일이 정해진 순서로 올라오도록 시퀀싱한다. PSU는 모든 레일이 규격 안에서 안정되면 'PWR_OK(Power Good)'를 띄운다. CPU 소켓 옆의 VRM(전압 조정 모듈)은 PSU가 준 12V를 CPU가 요구하는 약 1V의 코어 전압(Vcore)으로 다상(多相) 강압하고, VRM 자신도 안정되면 'VR_READY'를 올린다. 보드의 전원 시퀀싱이 이 신호들을 확인한 뒤에야 CPU의 리셋(PLTRST#)이 풀려 첫 명령을 실행할 수 있다. 전압이 불안정하면 CPU가 오작동하므로 이 단계가 반드시 선행되어야 한다.

**3. 기준 클럭 배포와 체배**

클럭 생성기가 크리스탈을 기준으로 100 MHz의 베이스 클럭(BCLK)과 PCIe·USB·SATA·메모리·DMI용 기준 클럭들을 만들어 트레이스로 각 소자에 배포한다(최신 인텔 플랫폼은 이 클럭 생성기가 PCH에 통합된다). CPU·GPU 내부의 PLL(위상 고정 루프)이 이 100 MHz를 수십 배로 체배해 GHz급 동작 클럭을 만든다. 모든 장치가 공통 기준 클럭에 맞춰 동기화되어야 신호를 서로 정확히 읽을 수 있기 때문이다.

**4. 펌웨어 부팅 경로 확보와 메모리 트레이닝**

CPU는 리셋이 풀리면 정해진 리셋 벡터(물리주소 0xFFFFFFF0, 4GB 최상단 부근)에서 첫 명령을 읽는데, 이 영역은 PCH가 메인보드의 SPI 플래시 롬(UEFI/BIOS)으로 디코딩·연결한다. 즉 초기 펌웨어 접근은 칩셋의 SPI 컨트롤러를 경유한다. UEFI는 DIMM 슬롯에 꽂힌 메모리와 '메모리 트레이닝'을 수행해, 다층 기판을 지나며 미세하게 어긋난 신호 타이밍·전압을 보정하고 안정 동작점을 찾는다. 이 과정이 끝나야 RAM을 정상 사용할 수 있다.

**5. 고속 장치의 CPU 직결 경로**

속도가 생명인 장치 — 그래픽카드(PCIe x16), 주 NVMe SSD(M.2, PCIe x4), 메모리(DIMM) — 는 칩셋을 거치지 않고 CPU에 직접 연결된 트레이스로 통신한다. 이 배선은 특성 임피던스를 규격값(예: PCIe 차동 약 85Ω, USB 약 90Ω, SATA 약 100Ω)에 맞추고, 차동 쌍 두 선과 여러 신호선의 길이를 나란히 맞춘(길이 정합) 차동 쌍으로 그려져, 수 GHz의 신호가 왜곡·지연 편차 없이 도달하도록 설계된다.

**6. 칩셋(PCH)의 집약과 DMI 업링크**

USB·SATA·추가 PCIe 슬롯·자체 다운스트림 PCIe 레인·이더넷 MAC·오디오·저속 I/O처럼 느리지만 수가 많은 장치는 칩셋이 한데 모아 관리한 뒤, DMI(다이렉트 미디어 인터페이스)라는 하나의 링크로 CPU에 전달한다. DMI는 전기적으로 PCIe와 같은 방식이며(최신 인텔 세대는 DMI 4.0 x8 = PCIe 4.0 x8에 상당, 약 16 GB/s 수준), 칩셋에 물린 모든 장치가 이 한 링크를 공유하므로 동시에 과도하게 쓰면 병목이 생길 수 있다. 느린 장치를 하나로 묶어 CPU의 귀한 고속 레인을 아끼는 구조다.

**7. 상시 관리 — 시계·발열·전원 상태·보안**

RTC(실시간 시계)는 32.768 kHz 크리스탈로 초를 세며, PSU가 꺼져도 CR2032 코인 배터리 덕분에 날짜·시간을 유지한다. 노트북의 EC(임베디드 컨트롤러)는 CPU가 잠들거나 꺼져 있어도 계속 돌며 배터리 충전, 팬 속도·발열, 키보드 매트릭스 스캔, 뚜껑·전원 버튼 감지, 절전 모드 진입·복귀를 관리한다. 데스크톱에서는 Super I/O 칩이 팬 제어·하드웨어 모니터링 등 일부 역할을 맡는다. 또한 칩셋의 관리 엔진(Intel ME/AMD PSP)이나 별도 TPM 칩이 부팅 무결성 검증·키 보관 같은 신뢰 루트 기능을 담당한다.

## 🧩 주요 부품

| 부품 | 하는 일 |
|---|---|
| **다층 PCB 기판 (FR-4)** | 유리섬유·에폭시(FR-4) 절연층과 구리층을 여러 겹 쌓아 만든 판. 저가형은 4층, 소비자 주류는 6~8층, 고급·오버클럭은 8~12층 이상으로, 신호층·전원 평면·접지 평면을 번갈아 배치해 모든 배선의 무대가 된다. |
| **구리 트레이스와 전원·접지 평면** | 신호가 흐르는 얇은 구리 선로(트레이스, 두께 대략 35µm/1oz)와, 넓게 깔린 전원 평면·접지 평면. 트레이스는 폭·간격·유전체 두께로 임피던스가 결정되고, 접지 평면은 리턴 경로와 노이즈 차폐를 제공한다. 전류가 큰 전원 평면은 2oz(약 70µm) 이상을 쓰기도 한다. |
| **CPU 소켓 (LGA + 리텐션)** | CPU를 앉히는 자리. 요즘 데스크톱은 LGA 방식(핀이 소켓 쪽, CPU는 평평한 접점)으로 수백~1800여 개 접점을 누른다(예: LGA1700/LGA1851). ILM(독립 로딩 메커니즘) 레버가 CPU를 균일하게 눌러 접촉을 확보한다. 노트북 CPU는 BGA로 기판에 직접 납땜된다. |
| **DIMM 메모리 슬롯** | RAM 모듈(DDR5 기준 288핀 DIMM)을 꽂는 슬롯. CPU 내장 메모리 컨트롤러(IMC)에 직결되며, 보통 2~4개가 채널로 배선된다. DDR5는 한 모듈이 2×32비트 독립 서브채널로 나뉘고, 전원 조정(PMIC)이 보드가 아닌 모듈 위로 옮겨와 5V 입력에서 약 1.1V를 자체 생성한다. 신호 타이밍을 맞추려 트레이스 길이를 정교하게 정합한다. |
| **M.2 슬롯** | NVMe SSD·Wi-Fi 모듈용 소형 슬롯. NVMe SSD는 주로 2280 크기의 M-키(PCIe x4, 일부 B+M키는 SATA)를 쓰고, Wi-Fi/BT 모듈은 별도의 2230 A+E 키 슬롯(CNVi 또는 PCIe x1+USB)을 쓴다. NVMe M.2는 한 개 정도가 CPU 직결, 나머지는 칩셋 경유 PCIe로 연결되는 경우가 많다. |
| **PCIe 확장 슬롯** | 그래픽카드용 x16(주로 CPU 직결)과 확장 카드용 x1·x4 슬롯(주로 칩셋 경유). 물리적으로 x16 크기여도 전기적으로는 x8·x4로 배선된 경우가 있어 겉모습과 실제 레인 수가 다를 수 있다. |
| **칩셋(PCH) 칩 + 히트싱크** | USB·SATA·추가 PCIe 레인·이더넷 MAC·저속 I/O·RTC·(Intel의) 관리 엔진을 품은 대형 I/O 허브 칩. 자체 다운스트림 PCIe 레인(최신 인텔 칩셋 20~28레인급)까지 제공하며 이 모두가 DMI x8를 공유한다. 발열이 있어 방열판이 덮인다. 사실상 오늘날 메인보드에서 CPU 외의 유일한 큰 칩이다. |
| **VRM (전압 조정 모듈)** | CPU 소켓 위·왼쪽에 늘어선 전원부. PWM 컨트롤러가 여러 '상(phase)'을 지휘하고, 각 상의 MOSFET(또는 통합 파워스테이지 DrMOS), 인덕터(초크), 캐패시터가 12V를 약 1V의 대전류(수십~수백 A) Vcore로 정밀 강압한다. 방열판이 덮인다. |
| **전원 커넥터 (24핀 ATX, 8핀 EPS)** | PSU에서 오는 전원을 받는 입구. 24핀 메인 커넥터가 3.3·5·12V와 대기 전원·제어 신호를, 8핀 EPS 커넥터가 CPU VRM용 12V를 집중 공급한다. 고전력 보드는 EPS를 8+8(또는 8+4)로 이중 배치하기도 한다. |
| **SPI 플래시 롬 (UEFI/BIOS)** | 부팅 펌웨어(UEFI)와 설정을 저장하는 작은 비휘발성 칩으로 PCH의 SPI 컨트롤러에 연결된다. 전원이 켜지면 CPU가 가장 먼저 읽는 부팅의 출발점이며, 대부분의 UEFI 설정도 여기 NVRAM 영역에 저장된다. |
| **RTC + 32.768kHz 크리스탈 + CMOS 배터리** | 실시간 시계(RTC)는 크리스탈로 초를 세어 날짜·시간을 유지한다. CR2032 코인 배터리(3V)가 컴퓨터 전원이 꺼져 있는 동안에도 RTC와 일부 설정 상태에 전력을 대준다. |
| **클럭 생성기 / 기준 크리스탈** | 100 MHz 베이스 클럭(BCLK)과 PCIe·USB·SATA·메모리·DMI용 기준 클럭들을 생성·분배한다. 최신 플랫폼은 상당 부분이 칩셋에 통합되지만, 별도 클럭 제너레이터 칩을 둔 보드도 있다. |
| **임베디드 컨트롤러(EC) / Super I/O** | 노트북의 EC는 CPU와 별개로 항상 돌며 전원 시퀀싱·배터리 충전·팬·키보드 스캔·전원 버튼·절전 복귀를 관리하는 작은 마이크로컨트롤러다. 데스크톱에서는 Super I/O 칩이 팬 제어·하드웨어 모니터링 등 일부를 담당한다. |
| **네트워크 소자 (이더넷 컨트롤러/PHY, Wi-Fi 모듈)** | 유선 랜은 두 방식이 있다. (a) 칩셋 내장 이더넷 MAC + 외부 PHY 칩, 또는 (b) MAC+PHY를 하나로 통합한 독립 PCIe 이더넷 컨트롤러(Realtek RTL8125, Intel i225/i226 등, 대개 2.5GbE)를 PCIe 레인에 물리는 방식. Wi-Fi는 CNVi 방식으로 MAC은 칩셋에, RF 모듈은 M.2(2230 A+E키) 카드에 나뉘어 실린다. |
| **오디오 코덱 칩과 SATA 포트** | 칩셋의 HD Audio(또는 최신 SoundWire) 인터페이스에 연결된 코덱 칩이 아날로그 소리(DAC/ADC)를 담당하며 후면 잭으로 연결된다. SATA 포트들은 칩셋의 SATA 컨트롤러에 물려 HDD·SATA SSD를 받는다. |
| **TPM / fTPM (신뢰 플랫폼 모듈)** | 부팅 무결성 측정과 암호 키·인증서를 안전하게 보관하는 보안 루트. 별도 TPM 칩(SPI/LPC 헤더에 장착)일 수도, 칩셋 ME/CPU에서 도는 펌웨어 TPM(Intel PTT / AMD fTPM)일 수도 있다. Windows 11의 TPM 2.0 요구 사항 때문에 사실상 표준 구성요소가 됐다. |
| **후면 I/O 패널·헤더·진단 LED** | USB·LAN·오디오 잭이 모인 후면 포트 패널, 팬·RGB·프론트패널 스위치용 핀 헤더, 그리고 부팅 단계 오류를 알려주는 진단 LED나 POST 코드 표시기가 기판 곳곳에 배치된다. |

## 📚 핵심 개념

| 용어 | 설명 |
|---|---|
| **칩셋 / PCH (Platform Controller Hub, 플랫폼 컨트롤러 허브)** | CPU에 직결하지 않는 USB·SATA·추가 PCIe·네트워크·저속 I/O를 모아 관리하고, 자체 다운스트림 PCIe 레인도 제공하는 Intel의 I/O 허브 칩. 예전 사우스브리지의 후신이며, AMD는 같은 역할을 FCH(Fusion Controller Hub)라 부른다. |
| **노스브리지·사우스브리지 (Northbridge / Southbridge)** | 과거 2칩 구조. 노스브리지는 메모리 컨트롤러·주 PCIe·내장 그래픽 등 고속을, 사우스브리지는 저속 I/O를 맡았다. 지금은 노스브리지 기능이 CPU 안으로 들어가 사실상 칩셋(PCH/FCH) 하나만 남았다. |
| **DMI (Direct Media Interface, 다이렉트 미디어 인터페이스)** | CPU와 칩셋을 잇는 인텔 전용 링크. 전기적으로 PCIe와 같은 방식이며, 칩셋에 물린 모든 장치가 이 한 링크를 공유해 CPU로 오간다. AMD는 DMI 대신 PCIe 기반 링크(예: X570/AM5 = PCIe 4.0 x4)를 쓴다. |
| **LGA / PGA / BGA (Land / Pin / Ball Grid Array)** | CPU 접점 방식. LGA는 핀이 소켓 쪽·CPU는 평평한 접점(요즘 데스크톱, AMD도 AM5부터 LGA), PGA는 핀이 CPU 쪽(AMD AM4 등 구형), BGA는 CPU를 기판에 납땜(노트북)해 교체 불가. |
| **DIMM (Dual In-line Memory Module)** | RAM 모듈의 형태. 이름의 'Dual In-line'은 모듈 앞·뒷면 접점이 각각 독립된 신호를 갖는다는 뜻으로, 양면 접점이 전기적으로 중복이던 옛 SIMM과 대비된다. 데스크톱은 DIMM, 노트북은 더 작은 SO-DIMM. DDR5 DIMM은 288핀이며 세대마다 홈(키) 위치가 달라 호환되지 않는다. |
| **PCIe (Peripheral Component Interconnect Express)** | 확장 장치용 직렬 고속 버스. 데이터를 '레인' 단위 차동 쌍으로 보내며 x1·x4·x8·x16으로 묶는다. 세대가 오를수록(3.0→4.0→5.0) 레인당 속도가 배로 늘어난다. |
| **VRM / 다상 벅 컨버터 (Voltage Regulator Module)** | 12V를 CPU용 약 1V 대전류로 낮추는 정밀 강압 회로. PWM 컨트롤러가 여러 '상'을 시간차로 번갈아 켜(인터리빙) 리플과 발열을 분산한다. 각 상은 MOSFET(또는 통합 DrMOS)·인덕터·캐패시터로 구성된다. |
| **RTC / CMOS (Real-Time Clock / Complementary Metal-Oxide-Semiconductor)** | RTC는 전원이 꺼져도 시간을 세는 시계. CMOS는 원래 배터리로 유지하던 저전력 설정 메모리를 부르던 이름이다. 요즘 설정 대부분은 SPI 플래시에 저장되고, 배터리는 주로 RTC 시각 유지에 쓰인다. |
| **EC / Super I/O (Embedded Controller)** | 메인 CPU와 별개로 항상 도는 작은 마이크로컨트롤러. 노트북 EC는 전원·배터리·팬·키보드·절전을 관리한다. 데스크톱에선 Super I/O 칩이 팬 제어·하드웨어 모니터링 일부를 맡는다. |
| **제어 임피던스 / 차동 쌍 (Controlled Impedance / Differential Pair)** | 고속 신호가 반사·왜곡 없이 흐르도록 트레이스의 특성 임피던스를 규격값에 맞추는 설계. 두 선의 전압 차로 신호를 전달하는 차동 쌍은 잡음에 강해 PCIe·USB·SATA·DDR에 쓰인다. 규격별 목표치가 달라(PCIe 약 85Ω, USB 약 90Ω, SATA/HDMI 약 100Ω) 각기 맞춘다. |
| **BCLK / PLL (Base Clock / Phase-Locked Loop)** | BCLK는 플랫폼의 기준 100 MHz 클럭. PLL(위상 고정 루프)은 이 기준을 수십 배로 체배해 CPU·PCIe 등의 동작 클럭을 만들어내는 회로다. |
| **IMC (Integrated Memory Controller, 내장 메모리 컨트롤러)** | 과거 노스브리지에 있다가 CPU 안으로 들어온 메모리 컨트롤러. DIMM 슬롯이 칩셋이 아니라 CPU에 직결되는 이유이며, RAM 속도·채널 수를 결정한다. |
| **CNVi / MAC·PHY (Integrated Connectivity / Media Access Control·Physical Layer)** | 네트워크의 논리부(MAC)와 물리부(PHY)를 나눈 구조. 이더넷은 (칩셋 내장 MAC + 외부 PHY) 또는 (MAC+PHY 통합 독립 PCIe 컨트롤러)로, Wi-Fi는 CNVi로 MAC은 칩셋에·RF 모듈은 M.2 카드에 나눠 싣는다. |
| **메모리 트레이닝 (Memory Training)** | 부팅 초기 UEFI가 메모리 신호의 타이밍·전압을 미세 조정해 안정 동작점을 찾는 과정. 기판을 지나며 생긴 신호 편차를 보정하기 때문에, 고속 램일수록 첫 부팅이 느려질 수 있다. |
| **TPM / fTPM (Trusted Platform Module)** | 부팅 무결성 측정값(PCR)과 암호 키를 안전하게 보관·증명하는 보안 하드웨어. 별도 칩(dTPM)일 수도, 칩셋/CPU에서 도는 펌웨어 구현(Intel PTT / AMD fTPM)일 수도 있다. 디스크 암호화(BitLocker)·보안 부팅의 신뢰 루트로, Windows 11이 TPM 2.0을 요구한다. |

## ⚠️ 흔한 오해

- **오해** — 메인보드가 직접 계산(연산)을 한다.
  <br>**교정** — 메인보드 자체는 연산하지 않고 연결·중계·전원 공급을 담당한다. 다만 칩셋·EC·Super I/O 같은 '작은 프로세서'들이 얹혀 관리 업무를 처리할 뿐, 프로그램 연산은 CPU가 한다.
- **오해** — 요즘도 노스브리지와 사우스브리지 두 칩이 있다.
  <br>**교정** — 메모리 컨트롤러·주 PCIe·내장 그래픽 등 노스브리지 기능은 모두 CPU 안으로 들어갔다. 지금 메인보드의 큰 칩은 사우스브리지 후신인 칩셋(PCH/FCH) 하나뿐이다.
- **오해** — 좋은 칩셋을 쓰면 CPU가 더 빨라진다.
  <br>**교정** — 칩셋은 포트 수·확장성·오버클럭 지원 여부 같은 'I/O 연결성'을 결정할 뿐, CPU의 연산 속도 자체는 CPU가 정한다. 상위 칩셋이라고 코어가 더 빨라지지는 않는다.
- **오해** — 모든 슬롯이 CPU에 직접 연결된다.
  <br>**교정** — 그래픽용 x16과 주 M.2 정도만 CPU 직결이고, 나머지 슬롯·USB·SATA는 칩셋을 거쳐 DMI 한 링크를 공유한다. 그래서 칩셋 장치를 동시에 몰아 쓰면 병목이 생길 수 있다.
- **오해** — CMOS 배터리가 컴퓨터에 전원을 공급해 부팅시킨다.
  <br>**교정** — 코인 배터리는 전원이 꺼진 동안 RTC 시계와 일부 설정을 유지하는 용도일 뿐이다. 배터리가 없거나 방전돼도 부팅은 되며, 다만 시간이 초기화되고 설정 유지에 문제가 생길 수 있다.
- **오해** — VRM은 그냥 전원을 이어주는 전선·부품이다.
  <br>**교정** — VRM은 12V를 CPU용 약 1V의 대전류로 낮추는 정밀 다상 강압 회로다. VRM의 상 수·방열·부품 품질이 CPU의 안정성과 오버클럭 여유를 좌우한다.
- **오해** — 메인보드 크기(ATX/mATX)만 다르지 기능은 다 같다.
  <br>**교정** — 폼팩터는 슬롯·포트 수와 확장성을 좌우하고, 어떤 칩셋을 쓰느냐가 지원 기능(오버클럭·PCIe 레인·USB 세대)을 크게 가른다. 껍데기만 다른 게 아니다.
- **오해** — DDR5 램은 보드가 1.2V를 공급해 돌린다(DDR4와 같은 방식).
  <br>**교정** — DDR5는 전원 조정(PMIC)을 모듈 위로 옮겨, 보드가 준 5V에서 모듈 스스로 약 1.1V를 만든다. 또 한 모듈이 2×32비트 서브채널로 나뉘어 DDR4(1×64비트)와 내부 구조가 다르다.

## 💡 비유

첫째, 메인보드는 도시의 기반 시설을 한 판에 새긴 것과 같다. CPU·GPU·RAM은 건물, 구리 트레이스는 도로, 전원부(VRM)는 고압을 가정용 전압으로 낮추는 변전소, 접지 평면은 도시 전체를 받치는 지반이다. 둘째, 칩셋(PCH)은 여러 지방 국도(USB·SATA·오디오·랜)를 한데 모아 CPU라는 고속도로 본선에 단 하나의 나들목(DMI)으로 합류시키는 교통 허브다. 급한 차(GPU·NVMe)는 본선에 직접 진입하고, 느리지만 수 많은 차들은 이 허브가 정리해 실어 나른다. 나들목이 하나뿐이라 러시아워엔 이 합류점(DMI)이 병목이 된다.

## 🔗 CAwiki 시나리오에서 만나는 곳

- 부팅(01): 전원 버튼 신호를 칩셋/EC가 받아 PSU를 깨우고, VRM이 12V를 약 1V로 낮춰 Power Good이 뜨면 CPU 리셋이 풀리며, 클럭 생성기가 100MHz 기준 클럭을 뿌린다. CPU는 칩셋 경유로 SPI 플래시의 UEFI를 읽어 부팅을 시작하고, TPM이 무결성을 측정하며, RTC가 현재 시각을 제공한다.
- USB를 꽂는 순간(12): 칩셋 안의 USB 호스트 컨트롤러가 새 장치를 감지·열거(enumeration)하고 장치 ID를 읽어 드라이버 로딩을 유발한다. 저속·다수 장치가 칩셋을 통해 CPU로 이어지는 전형적 경로다.
- 게임 렌더링(02): CPU의 드로우콜이 CPU 직결 PCIe x16 트레이스(길이·임피던스 정합된 차동 쌍)를 타고 GPU로 전달된다. 메인보드는 이 초고속 신호가 왜곡 없이 흐르도록 설계된 배선판 역할을 한다.
- 파일 열기·게임 로딩(04·15): NVMe SSD가 M.2 슬롯에 꽂혀 PCIe 레인으로 데이터를 쏟아낸다. 주 M.2는 CPU 직결, 추가 M.2는 칩셋 경유 PCIe를 통해 DMI 링크를 공유한다.
- 인터넷 검색(03): 칩셋 내장 MAC+외부 PHY거나 독립 PCIe 이더넷 컨트롤러, 또는 CNVi 방식 Wi-Fi 모듈이 네트워크 신호를 처리해 패킷이 공유기로 나가고 돌아온다.
- 소리 재생(08): 칩셋의 HD Audio 인터페이스가 외부 오디오 코덱(DAC)으로 신호를 보내 후면 잭·스피커로 소리가 나간다.
