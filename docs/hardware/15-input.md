# 입력장치
*Input Devices*

> 사람의 물리적 동작을 표준 디지털 입력 이벤트(주로 USB/Bluetooth HID)로 변환해 컴퓨터에 전달하는 장치군.

**분류**: 입출력

---

## 🧭 한마디로, 무슨 일을 하나
입력장치는 인간과 컴퓨터 사이의 '경계면'으로, 아날로그 세계의 물리량(압력, 위치 변화, 정전용량, 빛의 반사, 자기장)을 CPU가 처리할 수 있는 이산적 디지털 값으로 변환한다. 각 장치 안에는 자체 마이크로컨트롤러(MCU)가 들어 있어 센서를 스캔·샘플링하고 노이즈를 걸러낸 뒤 USB HID 같은 표준 프로토콜로 포장해 호스트로 보낸다. 덕분에 운영체제는 키보드·마우스·게임패드 제조사가 달라도 동일한 방식으로 입력을 해석한다. 컴퓨터가 하는 거의 모든 작업(부팅 시 키 입력, 검색어 타이핑, 게임 조작, 저장 단축키)은 입력장치가 만든 이벤트에서 시작된다. 참고로 이 문서는 사람이 조작해 이산 이벤트를 만드는 HID 계열(키보드·마우스·터치·게임패드·지문)을 중심으로 다루며, 마이크·카메라·스캐너 같은 장치도 넓은 의미의 입력장치이지만 이벤트가 아닌 오디오/영상 스트림 파이프라인을 쓰는 별개 경로다.

## ⚙️ 작동 방식

**1. 물리적 동작이 센서에서 아날로그 신호로 변환된다 (트랜스덕션)**

사용자가 키를 누르면 스위치 접점이 닿아 회로가 연결되고, 마우스를 움직이면 바닥면이 이동하며, 손가락이 화면에 닿으면 그 지점의 정전용량이 변한다. 각 센서(스위치·이미지센서·전극격자·포텐셔미터·홀센서·정전판)는 서로 다른 물리량을 전압·전류·정전용량·자기장 변화 같은 전기 신호로 바꾼다. 컴퓨터가 압력이나 빛 자체를 이해할 수 없어 우선 전기적 값으로 옮겨야 하기 때문이다.

**2. 컨트롤러가 센서를 주기적으로 스캔·샘플링한다**

장치 내부 MCU가 아주 빠른 주기로 센서 상태를 읽는다. 키보드는 키 매트릭스의 행(row)에 순서대로 전압을 걸고 열(column)의 반응을 읽어 어느 교차점이 눌렸는지 알아내는 '매트릭스 스캔'을 초당 수백~수천 번 반복한다. 마우스 광센서는 초당 수천~수만 프레임의 바닥 이미지를 찍고, 터치 컨트롤러는 전극 격자를 훑고, 게임패드는 스틱 포텐셔미터/홀센서 전압을 ADC로 디지털화한다. 상태를 '연속'이 아니라 '주기적 샘플'로 읽어야 디지털 회로가 다룰 수 있기 때문이다.

**3. 노이즈·바운스를 제거하고 원시 데이터를 해석한다 (디바운스·신호처리)**

기계 접점은 붙는 순간 대략 1~5 ms 동안 미세하게 떨려(bounce) 한 번 누름이 여러 번으로 읽힐 수 있어, 펌웨어가 신호가 안정될 때까지(통상 5 ms 안팎, 최신 게이밍 키보드는 0.5~1 ms급 알고리즘) 기다렸다가 하나의 눌림으로 확정한다(디바운싱). 마우스 DSP는 연속 두 프레임의 무늬를 상관(cross-correlation) 비교해 이동 방향·거리(Δx, Δy)를 계산하고, 터치 컨트롤러는 여러 전극에 걸친 정전용량 변화의 무게중심(centroid)을 보간해 정밀 좌표를 구한다. 물리 세계의 불완전함을 정제해 '진짜 의도된 입력'만 남기는 단계다.

**4. 결과를 표준 HID 리포트로 인코딩한다 (부트 vs 리포트 프로토콜)**

MCU는 처리된 입력을 미리 약속된 데이터 형식으로 채운다. 형식은 두 가지 모드가 있다. 하나는 BIOS/UEFI가 드라이버 없이 알아듣는 고정 '부트 프로토콜'로, 키보드 부트 리포트는 8바이트(수정키 1바이트 + 예약 1바이트 + 동시 눌린 키 코드 6바이트)라 동시 6키(6KRO)가 상한이다. 다른 하나는 OS가 로드된 뒤 쓰는 '리포트 프로토콜'로, HID 리포트 디스크립터가 정의한 유연한 형식(예: 키 전체를 비트맵으로 표현해 NKRO)을 사용한다. 마우스 리포트는 버튼 비트 + Δx/Δy + 휠 값이다. 좌표·버튼·스캔코드를 표준 자리에 배치해야 어떤 운영체제든 해석할 수 있어 이 인코딩이 호환성의 핵심이다.

**5. USB 인터럽트 전송으로 호스트에 전달된다 (폴링)**

USB는 장치가 스스로 말을 걸 수 없는 호스트 주도 방식이라, 호스트 컨트롤러가 정해진 간격(bInterval)마다 '보낼 데이터 있나?'라고 묻고 장치가 준비된 리포트로 답한다. 이 인터럽트 전송은 대역폭은 작아도 '지연 시간의 상한이 보장'된다. 게이밍 마우스는 1 ms(1000 Hz)마다, 일반 키보드는 관례적으로 약 8 ms(125 Hz)마다 응답한다. 참고로 8000 Hz(0.125 ms)급 초고속 폴링은 마이크로프레임(125 µs) 단위를 쓰는 하이스피드 장치에서만 가능하고, 로우/풀스피드로는 그 속도가 나오지 않는다. 실시간성이 중요한 입력에 딱 맞는 전송 방식이다.

**6. 호스트 드라이버·OS가 리포트를 이벤트로 변환한다**

USB 스택이 리포트를 받으면 HID 드라이버가 디스크립터에 따라 해석해 스캔코드/좌표/버튼 상태로 풀고, OS 입력 서브시스템이 이를 '키다운', '마우스이동', '터치' 같은 이벤트로 만들어 현재 포커스된 애플리케이션에 전달한다. 여기서 키 스캔코드(HID Usage ID)는 키맵을 거쳐 실제 문자로, 마우스 Δ값은 (가속·감도 곡선을 거쳐) 화면 커서 위치로 번역된다.

**7. 필요 시 출력 방향의 되먹임(햅틱·LED)이 발생한다**

입력장치는 순수 입력만 하는 게 아니라 호스트로부터 명령(HID Output/Feature 리포트)을 받기도 한다. 게임에서 총을 쏘면 호스트가 게임패드로 진동 세기 값을 내려보내 럼블 모터를 돌리고, Caps Lock을 켜면 키보드 LED가 켜진다. 이 역방향 흐름 덕분에 사용자는 자기 입력이 반영됐음을 촉각·시각으로 즉시 확인한다.

## 🧩 주요 부품

| 부품 | 하는 일 |
|---|---|
| **키 스위치 (기계식/멤브레인/광학)** | 키보드에서 실제로 눌림을 감지하는 접점. 기계식은 스프링과 금속 접점을 쓰는 개별 스위치(예: 청/적/갈축)로 명확한 촉감과 긴 수명(5천만~1억 회)을 주고, 멤브레인/러버돔은 고무 돔이 눌리며 두 필름의 도전층을 맞닿게 해 값싸고 조용하지만 촉감이 뭉툭하다. 광학식은 빛 차단으로 눌림을 감지해 접점 바운스가 없다. |
| **키 매트릭스 회로 (행·열 격자 + 다이오드)** | 모든 키를 개별 배선하지 않고 행렬로 엮어, 적은 핀 수로 많은 키를 읽게 한다. 컨트롤러가 행에 전압을 걸고 열을 읽어 교차점을 특정한다. 각 키에 다이오드를 달아 전류 역류를 막으면 여러 키 동시 입력 시 유령 입력(ghosting)을 방지하고 N키 롤오버(NKRO)를 구현한다. |
| **장치 마이크로컨트롤러 (MCU) / 컨트롤러 IC** | 입력장치의 두뇌. 센서 스캔, 디바운스, 좌표·이동량 계산, HID 리포트 생성, USB/무선 통신을 담당하는 소형 프로세서. 키보드·마우스·게임패드마다 각자의 펌웨어가 올라간 전용 칩이 들어 있다. |
| **광/레이저 이미지 센서 + DSP (마우스)** | LED(주로 적색) 또는 IR 레이저로 바닥을 비추고, 작은 CMOS 이미지 센서 배열이 표면 무늬를 초당 수천~수만 프레임으로 촬영한다. 내장 DSP가 프레임 간 무늬 이동을 상관 분석해 이동 방향·거리(Δx, Δy)를 산출한다. |
| **정전용량 전극 격자 + 터치 컨트롤러 (터치스크린)** | 투명 전도막(ITO 등)으로 만든 가로(구동)·세로(감지) 전극이 격자를 이룬다. 손가락이 닿으면 해당 교차점의 상호 정전용량이 변하고, 터치 컨트롤러가 격자를 스캔해 변화의 무게중심으로 (x, y) 좌표와 다중 터치를 계산한다. |
| **능동형 스타일러스 / 디지타이저** | 터치 계열의 정밀 입력 부품. 전자기 유도(EMR) 방식 디지타이저나 정전 결합식 능동 펜은 펜촉 위치뿐 아니라 필압(수백~수천 단계)과 기울기까지 읽어, 손가락 터치보다 정밀한 필기·드로잉 좌표를 만든다. |
| **아날로그 스틱 (포텐셔미터/홀센서) + ADC** | 게임패드의 스틱은 X·Y 두 축의 저항(포텐셔미터) 또는 홀 효과 센서로 기울기를 전압으로 바꾸고, ADC가 이를 디지털 값으로 읽어 방향·세기를 연속적으로 표현한다. 중심 근처 미세 떨림을 무시하는 데드존 처리가 들어간다. |
| **햅틱 액추에이터 (진동 모터)** | 역방향 피드백 담당. 편심 회전 모터(ERM)나 선형 공진 액추에이터(LRA), 최신 컨트롤러의 보이스코일형 정밀 햅틱이 호스트 명령에 따라 진동을 만들어 타격감·질감을 전달한다. |
| **지문 센서 어레이 (정전/광학/초음파)** | 손가락 표면의 융선(마루)과 골을 읽는다. 정전식은 미세 정전판 배열이 융선/골의 거리 차로 생기는 정전용량 차를 이미지화하고, 광학식은 빛 반사로 지문 이미지를 찍으며, 초음파식은 음파가 융선/골에서 반사되는 시간·강도로 표면의 3D 요철을 재구성한다(화면 아래 배치·젖은 손가락에 유리). 원본 대신 특징점(minutiae) 템플릿을 추출해 보안 영역에 저장한다. |
| **USB/무선 인터페이스 회로** | 장치와 호스트를 잇는 통로. 유선은 USB 트랜시버가 인터럽트 전송으로 리포트를 주고받고, 무선은 2.4 GHz 전용 동글이나 Bluetooth 무선 모듈이 같은 HID 데이터를 무선으로 실어 나른다. |
| **펌웨어 / HID 리포트 디스크립터** | MCU 안의 소프트웨어와, 이 장치가 '어떤 형식의 데이터를 보내는지' 호스트에 알려주는 자기소개서. 디스크립터 덕분에 별도 드라이버 없이도 OS가 장치의 버튼·축·키 배치를 이해한다. |
| **인코더 / 스크롤 휠 (마우스)** | 휠 회전을 광학 또는 기계식 인코더로 감지해 스크롤 스텝(노치) 또는 연속 스크롤 값으로 변환한다. 클릭 버튼은 마이크로 스위치(택트 스위치)로 눌림을 감지한다. |

## 📚 핵심 개념

| 용어 | 설명 |
|---|---|
| **HID (Human Interface Device, 휴먼 인터페이스 디바이스)** | USB/Bluetooth 표준의 장치 클래스. 키보드·마우스·게임패드처럼 사람이 조작하는 장치가 '리포트 디스크립터'로 데이터 형식을 스스로 알려, 제조사 전용 드라이버 없이 OS가 곧바로 인식·해석하게 하는 규약. |
| **부트 프로토콜 vs 리포트 프로토콜 (Boot vs Report Protocol)** | HID 키보드/마우스의 두 동작 모드. 부트 프로토콜은 BIOS/UEFI가 드라이버 없이 알아듣도록 형식이 고정돼 있어(키보드 8바이트, 동시 6키 상한) 부팅·펌웨어 환경에서 쓰인다. OS가 뜬 뒤에는 디스크립터가 정의한 유연한 리포트 프로토콜로 전환해 NKRO·추가 버튼·다축 등 풍부한 형식을 쓴다. |
| **인터럽트 전송 (Interrupt Transfer)** | USB의 4가지 전송 방식 중 하나. 대역폭은 작지만 호스트가 정해진 주기로 폴링하여 '최대 지연 시간이 보장'된다. 키·마우스처럼 반응성이 중요한 소량·주기적 데이터에 쓰인다. 이름과 달리 장치가 능동으로 끼어드는 게 아니라 호스트가 주기적으로 물어본다. |
| **폴링 레이트 (Polling Rate)** | 호스트가 장치에게 데이터를 얼마나 자주 물어보는지의 빈도(Hz). 1000 Hz는 1 ms마다, 125 Hz는 8 ms마다 갱신을 뜻한다. 높을수록 커서·조준이 부드럽고 지연이 낮지만, 아주 높은 값(8000 Hz)은 하이스피드 USB에서만 가능하고 체감 이득 대비 CPU 부하가 커진다. |
| **키 매트릭스 스캔 (Key Matrix Scanning)** | 키를 행·열 격자로 배선하고, 행에 순차로 신호를 넣으며 열의 반응을 읽어 눌린 키를 찾아내는 방식. 100여 개 키를 개별 배선(100핀) 대신 소수의 핀(예: 8행×18열=26핀)으로 처리하게 해준다. |
| **디바운싱 (Debouncing)** | 기계 접점이 붙거나 떨어질 때 대략 1~5 ms 동안 미세하게 튕겨(bounce) 한 번 동작이 여러 번으로 읽히는 현상을, 신호가 안정될 때까지 잠깐(통상 5 ms 안팎) 기다렸다가 하나로 확정하는 처리. 광학식 스위치는 접점 바운스가 없어 이 대기가 필요 없다. |
| **스캔코드 (Scan Code) / HID 사용 ID (Usage ID)** | 키의 '물리적 위치'를 나타내는 코드. 실제 문자가 아니라 자리 번호다(같은 자리라도 키맵에 따라 다른 문자가 됨). 옛 PS/2는 스캔코드 세트(1·2·3)를, USB 키보드는 HID Usage ID를 쓴다. |
| **DPI/CPI (Dots/Counts Per Inch, 인치당 카운트)** | 마우스를 1인치 움직였을 때 센서가 보고하는 이동 카운트 수. 높을수록 조금만 움직여도 커서가 많이 이동한다. 감도(민감도)이지 정밀도·추적 정확도 자체는 아니다. |
| **상호 정전용량 vs 자기 정전용량 (Mutual vs Self Capacitance)** | 정전식 터치의 두 감지 방식. 상호 정전용량은 구동 전극과 감지 전극 사이 정전용량으로, 손가락이 오면 전기장 일부가 새어 값이 줄고 격자 교차점별로 측정해 여러 손가락 위치를 동시에(멀티터치) 구분한다. 자기 정전용량은 전극과 대지 사이 용량이 손가락 접촉으로 늘어나는 것을 보는데, 축별 합산이라 다중 터치 좌표 분리에 불리하다. |
| **N키 롤오버(NKRO) / 6KRO / 고스팅** | 여러 키를 동시에 눌렀을 때 매트릭스 회로가 겹쳐 누르지 않은 유령 키가 감지되는 현상이 고스팅. 각 키에 다이오드를 넣어 전류 역류를 막고 비트맵 리포트(리포트 프로토콜)를 쓰면 몇 개를 눌러도 모두 인식되는 NKRO가 된다. 반면 BIOS 등에서 쓰는 부트 프로토콜은 8바이트 구조상 동시 6키(6KRO)가 상한이다. |
| **포텐셔미터 / 홀 효과 센서 (Potentiometer / Hall-effect Sensor)** | 게임패드 아날로그 스틱의 위치 감지 소자. 포텐셔미터는 접촉식 가변저항이라 마모로 드리프트가 생길 수 있고, 홀 센서는 자기장 변화를 비접촉으로 읽어 마모가 없다. |
| **햅틱 액추에이터: ERM / LRA (Eccentric Rotating Mass / Linear Resonant Actuator)** | 진동을 만드는 부품. ERM은 무게추가 편심 회전해 둔탁하게 흔들고, LRA는 질량을 선형 공진시켜 더 빠르고 세밀한 진동을 낸다. 최신 컨트롤러는 보이스코일형 정밀 햅틱으로 질감까지 표현한다. |
| **미뉴셔 (Minutiae, 특징점)** | 지문의 융선이 끊기거나 갈라지는 지점 같은 고유 특징. 지문 인증은 이미지 전체가 아니라 이 특징점들의 배치를 템플릿으로 뽑아 비교하며, 원본은 보안 영역에 안전하게 보관한다. |

## ⚠️ 흔한 오해

- **오해** — 높은 DPI 마우스가 무조건 더 정밀하고 좋다.
  <br>**교정** — DPI는 '정밀도'가 아니라 '감도'다. 너무 높으면 1픽셀 단위 조작이 어려워 오히려 부정확해진다. 실제 정밀 조준은 낮은~중간 DPI에서 더 잘 되는 경우가 많고, 센서 품질·폴링레이트·추적 정확도가 더 중요하다.
- **오해** — 폴링레이트가 높을수록(예: 8000 Hz) 항상 체감이 좋아진다.
  <br>**교정** — 1000 Hz면 1 ms 지연으로 대부분 사용에 충분하다. 그 이상은 체감 이득이 급격히 줄고 CPU 부하만 늘 수 있으며, 8000 Hz는 하이스피드 USB가 뒷받침돼야 한다. 무조건 최고치가 최선은 아니다.
- **오해** — 키보드 스캔코드가 곧 그 키의 문자다.
  <br>**교정** — 스캔코드/HID Usage ID는 키의 '물리적 위치 번호'일 뿐이다. 실제 문자는 OS의 키맵(레이아웃)이 결정한다. 그래서 같은 키보드도 한글/영문/QWERTY/AZERTY 설정에 따라 다른 문자가 나온다.
- **오해** — 정전식 터치스크린은 압력을 감지해 눌린 세기를 안다.
  <br>**교정** — 정전식은 압력이 아니라 손가락과 전극 사이 '정전용량 변화'를 감지한다. 그래서 아주 살짝 닿아도 반응하고, 반대로 전기가 통하지 않는 물체(일반 장갑·플라스틱 펜)에는 반응하지 않는다. 압력감은 별도 필압 센서나 정전용량 접촉 면적 추정으로 흉내 낸다.
- **오해** — USB 인터럽트 전송은 장치가 필요할 때 CPU에 인터럽트를 거는 방식이다.
  <br>**교정** — 이름과 달리 장치가 능동으로 끼어드는 게 아니다. USB는 호스트 주도라, 호스트가 정해진 주기로 '데이터 있냐'고 폴링하고 장치는 준비된 응답을 줄 뿐이다. 최대 지연이 보장된다는 의미에서 '인터럽트'라 부른다.
- **오해** — 장갑을 끼면 정전식 화면이 안 되는 건 화면이 고장나서다.
  <br>**교정** — 고장이 아니라 원리 때문이다. 손가락의 전도성이 있어야 전극의 정전용량을 바꾸는데, 절연성 장갑이 이를 막는다. 손끝이 통하는 '터치용 장갑'이나 정전식 스타일러스는 정상 작동한다.
- **오해** — 지문은 이미지 그대로 저장돼 유출되면 원본이 새어 나간다.
  <br>**교정** — 대부분의 기기는 지문 원본 이미지 대신 특징점(미뉴셔) 기반 수학적 템플릿만 보안 영역(예: 보안 엔클레이브)에 저장하고, 원본 이미지로 되돌릴 수 없게 설계한다. 그래도 생체정보이므로 안전한 저장이 중요하다.
- **오해** — 기계식 키보드가 멤브레인보다 항상 더 빠르게 입력된다.
  <br>**교정** — 입력 지연은 스위치 종류보다 스캔·디바운스·폴링 처리, USB 전송 주기에 더 좌우된다. 기계식의 장점은 주로 촉감·내구성·NKRO이며, 절대 반응속도 차이는 생각만큼 크지 않을 수 있다.
- **오해** — 무선 마우스·키보드는 유선보다 항상 입력 지연이 크다.
  <br>**교정** — 과거엔 그랬지만, 최신 2.4 GHz 전용 무선은 유선과 거의 차이 없는 ~1 ms 수준까지 왔다. 다만 Bluetooth는 프로토콜 특성상 상대적으로 지연·간섭·연결 안정성 면에서 불리할 수 있어, 무선 방식에 따라 다르다.
- **오해** — 터치 반응 속도는 화면 주사율(예: 120 Hz)이 정한다.
  <br>**교정** — 화면이 얼마나 자주 그려지는지(리프레시레이트)와, 터치 컨트롤러가 손가락 위치를 얼마나 자주 읽는지(터치 샘플링레이트)는 별개다. 120 Hz 화면에 240 Hz 터치 샘플링이 함께 쓰일 수 있고, 손가락을 따라오는 즉각성은 후자에 더 좌우된다.

## 💡 비유

비유 1: 입력장치는 '통역사'다. 사람이 하는 물리적 몸짓(키 누름·손 이동·터치)이라는 외국어를, 컴퓨터가 알아듣는 표준 문장(HID 리포트)으로 실시간 통역해 전달한다. 비유 2: USB 인터럽트 전송의 폴링은 '수업 중 선생님이 정해진 간격으로 학생에게 손 들 것 있냐고 물어보는 것'과 같다. 학생(장치)이 아무 때나 소리치는 게 아니라, 선생님(호스트)이 주기적으로 확인해 주니 발언 순서와 최대 대기 시간이 보장된다. 비유 3: 키 매트릭스 스캔은 '아파트 우편함'과 같아서, 층(행)과 호수(열)의 교차로 위치를 특정해 적은 배선으로 많은 키를 구분한다.

## 🔗 CAwiki 시나리오에서 만나는 곳

- 부팅(boot): 전원을 켜고 BIOS/UEFI 화면에서 Del·F2 키를 누르면, USB HID 키보드가 '부트 프로토콜'의 8바이트 리포트를 보내 펌웨어가 이를 인식하고 설정 메뉴로 진입한다. OS가 완전히 뜨기 전에도 동작하는 최소한의 입력 경로이며, 이때는 동시 6키(6KRO)까지만 인식된다.
- 인터넷 검색 왕복(search): 검색창에 주소나 검색어를 타이핑하는 순간마다 키보드 스캔→디바운스→HID 리포트→OS 키이벤트→브라우저 입력으로 이어지고, 마우스로 링크를 클릭해 요청을 시작한다.
- 게임 렌더링(game): 마우스 이동(Δx, Δy)과 게임패드 아날로그 스틱 값이 초당 수백~수천 번 갱신되어 시점·캐릭터를 조작하고, 총을 쏘면 호스트가 게임패드로 진동 명령을 되돌려보내 햅틱 피드백을 준다.
- 파일 열기: 파일 탐색기에서 마우스로 항목을 더블클릭하거나 방향키·Enter로 파일을 선택해 여는 동작이 모두 입력장치 이벤트에서 출발한다.
- Ctrl+S 저장: 키보드가 수정키(Ctrl) 비트와 S키 스캔코드를 같은 HID 리포트에 담아 보내고(동시 입력 인식), OS가 이를 단축키 이벤트로 조합해 앱의 저장 명령을 트리거한다. NKRO/다이오드가 동시 키 인식을 보장하는 대표 장면.
- AI 질문: 사용자가 프롬프트를 길게 타이핑하는 전 과정이 키보드 입력 파이프라인을 거치며, 모바일에서는 정전식 터치스크린이 가상 키보드 좌표를 계산해 같은 역할을 한다.
- 스마트폰 잠금 해제·결제 인증: 지문 센서가 융선/골을 정전(또는 광학·초음파)으로 이미지화해 특징점 템플릿과 대조하고, 일치하면 보안 영역이 인증을 승인한다.
- 영상 스트리밍: 리모컨/터치/마우스로 재생·일시정지·볼륨을 조작하는 등, 미디어 소비 중의 모든 제어 입력이 입력장치를 통한다.
