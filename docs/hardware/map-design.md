# 실리콘 아틀라스 — 지도 페이지 디자인 시안

2026-10-07. 검토 주소: `/map-design.html`.

기존의 어두운 배경, 구리색 강조, 단계별 설명과 카메라 전환을 3D 공간으로 옮긴
작동 가능한 디자인 시안입니다. 메인 화면의 **새 지도 디자인** 링크에서 열 수 있습니다.

## 화면 구성

- 위: CAwiki 브랜드, 지도·작동 원리, 부품 도감 이동.
- 왼쪽: 한 문장 제목 → 역할 설명 → 핵심 개념 → 함께 일하는 부품 → 자세히 보기.
- 오른쪽: 3D 부품, 이름표, 데이터 연결선, 전체 지도와 직접 회전 도구.
- 아래: 전체 지도 / 연산 / 메모리 / 그래픽 / 저장 / 네트워크 / 전원의 7단계.
- 모바일: 제목 → 3D 모델 → 설명 → 단계 이동 순서로 재배치합니다.

첫 장면은 여덟 개의 실제 3D 모델을 분해된 배치로 보여줍니다. 부품을 선택하면 해당
모델이 앞으로 이동·확대되고 주변 부품은 흐려집니다. 함께 일하는 두 부품과 연결선은
남아 문맥을 유지합니다. 도면은 연결 관계를 설명하는 배치로, 실제 조립 치수나 배선
위치를 나타내지 않습니다. 세부 모델 재현 범위는 `3d-models.md`를 참고하세요.

## 모션과 조작

- 카메라와 부품 배치: 1,150 ms ease-out 전환.
- 설명: 620 ms 위로 등장, 요소별 35 ms 간격.
- 데이터 경로: 구리색 선을 따라 작은 광점이 이동합니다.
- 휠은 제스처당 한 단계만 진행하며 남은 관성 입력은 흡수합니다.
- 키보드: 방향키 / PageUp·Down / Space, Home·End, Escape로 전체 지도 복귀.
- 모델과 이름표, 하단 단계, 관련 부품 버튼으로 직접 이동할 수 있습니다.
- 모바일 모델 영역을 위아래로 밀면 단계가 바뀝니다. 설명 영역은 일반 스크롤입니다.
- 직접 돌려보기에서는 드래그 회전과 휠·핀치 확대를 사용합니다.
- 모션 감소 설정에서는 카메라·텍스트 전환과 광점 움직임을 멈춥니다.
- WebGL 미지원·연결 손실 시 같은 모델의 PNG와 설명으로 탐색을 계속합니다.

## 파일

- `map-design.html`: 디자인 시안 셸.
- `assets/map-design.css`: 페이지 레이아웃, 타이포그래피, 반응형 디자인.
- `lib/map-design-content.js`: 설명과 챕터별 구성.
- `lib/map-design.js`: 3D 장면, 카메라·설명 전환, 탐색 조작.
- `tests/map-design.py`: 브라우저 검증. 기존 `serve.py` 서버와 Python Playwright를 사용합니다.
- `artifacts/map-design-*.png`: 데스크톱 전체 지도·CPU 설명·모바일 검토 이미지.

기존 모델 라이브러리와 스튜디오를 재사용하며 별도 빌드나 CDN은 필요하지 않습니다.
