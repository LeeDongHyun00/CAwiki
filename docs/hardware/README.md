## 🔌 하드웨어 연결 지도

빠른 장치는 CPU에 직결하고, 느린 다수는 칩셋(PCH)이 모아 전달합니다. 각 문서의 **연관 하드웨어** 표에 세부 연결이 있습니다.

```mermaid
flowchart TB
  CPU[CPU] --- SRAM[SRAM 캐시·레지스터]
  CPU --- RAM[RAM DRAM]
  CPU --- GPU[GPU]
  CPU -.->|내장| NPU[NPU]
  GPU --- VRAM[VRAM]
  GPU -->|HDMI·DP| MON[모니터]
  CPU ---|PCIe·DMI| BUS{{버스·인터커넥트}}
  BUS --- SSD[SSD]
  BUS --- PCH[메인보드·칩셋]
  CPU -.->|부팅 첫 명령| SPI[SPI 플래시 롬]
  PCH --- HDD[HDD]
  PCH --- NIC[NIC·Wi-Fi]
  PCH --- AUD[오디오]
  PCH --- INP[입력장치]
  PCH --- CAM[카메라·웹캠]
  PCH --- SPI
  NIC --- INFRA[홈·인터넷 인프라] --- DC[데이터센터]
  PSU[전원부 PSU·VRM] -.->|급전| CPU
  PSU -.->|급전| GPU
  PSU -.->|급전| PCH
  COOL[냉각] -.->|방열| CPU
  COOL -.->|방열| GPU
  COPROC[보조 프로세서·MCU] -.->|내장| SSD
  COPROC -.->|내장| CAM
  COPROC -.->|내장| AUD
```
