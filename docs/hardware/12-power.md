# 전원부 (PSU · VRM · 배터리)
*Power Supply, VRM & Battery*

> 벽 콘센트의 수백 볼트 교류(AC)를 부품이 쓸 수 있는 안정된 저압 직류(DC)로 바꾸고, 다시 각 칩이 요구하는 정확한 전압(약 1V)까지 낮춰 공급하는 컴퓨터의 심장이자 순환계.

**분류**: 기판·버스·전원

---

## 🧭 한마디로, 무슨 일을 하나
PSU(파워서플라이)는 콘센트의 교류(국내 표준 220V·60Hz, 지역에 따라 100~120V·50/60Hz)를 +12V·+5V·+3.3V 직류로 변환해 시스템 전체에 공급하고, VRM(전압 조정 모듈)은 그 12V를 CPU·GPU가 요구하는 약 1V(부하·전력상태에 따라 대략 0.7~1.4V) 수준으로 다시 낮춰 상(phase)당 초당 수십만~수백만 번 스위칭하며 고부하 시 수백 암페어를 안정적으로 흘린다. 노트북에서는 리튬이온 배터리와 충전 회로·PMIC(전력관리 IC)가 콘센트 없이도 같은 일을 하며, 부하에 따라 전압과 클럭을 실시간으로 조절해 에너지를 아낀다. 전원이 규격 범위 안에서 안정돼야만 Power Good 신호가 떠서 CPU의 리셋이 풀리고 비로소 컴퓨터가 깨어난다. 즉 전원부는 모든 연산의 전제 조건이며, 성능·안정성·전력효율을 동시에 좌우하는 토대다.

## ⚙️ 작동 방식

**1. AC 입력 · EMI 필터 · 돌입전류 제한**

콘센트에서 들어온 교류(대략 220~240V 또는 100~120V, 50/60Hz)가 먼저 EMI/라인 필터(X·Y 커패시터와 공통모드 초크)를 통과한다. 이 필터는 PSU 내부의 고주파 스위칭 노이즈가 전력망으로 새어 나가거나 외부 서지가 안으로 들어오는 것을 양방향으로 막는다. 동시에 NTC 서미스터(또는 릴레이 바이패스)가 전원을 켜는 순간 커패시터로 한꺼번에 몰리는 돌입 전류(inrush current)를 억제해 퓨즈가 끊기거나 부품이 손상되는 것을 방지한다.

**2. 정류(Rectify) — 교류를 한 방향으로**

브리지 정류기(다이오드 4개)가 교류의 음(−)의 반주기를 위로 뒤집어(전파정류), 전류가 항상 한 방향으로만 흐르는 맥동 직류(pulsating DC)로 만든다. 아직 전압이 크게 출렁이는 상태라 그대로는 쓸 수 없다. 정류를 하는 이유는 컴퓨터 회로가 극성이 일정한 직류만 다룰 수 있기 때문이다.

**3. 능동 PFC + 평활 — 매끈한 고압 DC 버스 만들기**

능동 PFC(역률 개선) 회로가 부스트 컨버터로 입력 전류 파형을 전압 파형과 같은 모양으로 끌어당겨 역률을 대략 0.99까지 높인다(전력망을 효율적으로 쓰고 고조파 왜곡을 줄이기 위함). 이 과정에서 대용량 벌크 커패시터가 맥동의 골을 메워, 대략 380~400V의 매끈한 고압 DC 버스를 만든다. (230V를 단순 정류만 하면 피크가 약 325V(230×√2)이므로, PFC 부스트가 이보다 높게 끌어올린다.)

**4. 고주파 스위칭 · 변압기 절연 · 강압**

1차측 스위칭 MOSFET들(보통 하프브리지 LLC나 풀브리지 구성)이 이 고압 DC를 대략 수십~수백 kHz로 잘게 끊어(스위칭) 메인 트랜스포머 1차 코일에 넣는다. 트랜스포머는 전압을 낮춰 주면서, 위험한 콘센트 쪽(1차)과 사람이 만지는 컴퓨터 쪽(2차)을 전기적으로 절연(isolation)한다. 스위칭 주파수가 높을수록 같은 전력을 더 작은 변압기·커패시터로 처리할 수 있어 PSU가 작고 가벼워진다. 이 방식을 스위칭 전원(SMPS)이라 부른다.

**5. 2차측 정류·평활 → 12V/5V/3.3V 레일 생성**

변압기 2차측에서 다시 정류(요즘은 손실이 적은 동기정류 MOSFET 사용)·평활해 주 레일인 +12V를 만들고, DC-DC 컨버터가 그 12V에서 +5V와 +3.3V를 파생한다(현대적 DC-DC 설계; 과거 그룹 레귤레이션 방식과 대비). 출력 전압은 옵토커플러+기준전압 IC(TL431)를 통해 절연 장벽을 넘어 1차측 컨트롤러로 피드백되어 부하가 변해도 일정하게 유지된다. 콘센트에 꽂혀 있는 한 항상 켜져 있는 +5VSB(대기) 레일은 별도의 소형 플라이백 컨버터가 담당하며, 이것이 있어야 전원 버튼·Wake-on-LAN 등이 꺼진 상태에서도 동작한다.

**6. Power Good 신호 · CPU 리셋 해제**

모든 레일이 규격 범위(예: +12V·+5V·+3.3V는 대략 ±5%) 안으로 안정되면 PSU가 대략 100~500ms 뒤에 Power Good(PWR_OK) 신호를 High(약 5V, 일부 설계는 3.3V 로직)로 올린다. 이 신호가 뜨기 전까지 칩셋과 CPU는 리셋 상태에 붙잡혀 있다. 신호가 뜨는 순간 CPU의 리셋이 풀리고 CPU는 미리 정해진 주소(리셋 벡터)에서 첫 명령을 가져와 부팅을 시작한다. 즉 Power Good은 '이제 안심하고 일 시작해도 된다'는 전원부의 허가 신호다.

**7. VRM 다상 강압 — 12V를 약 1V로**

메인보드·그래픽카드의 VRM이 12V를 받아, PWM 컨트롤러가 여러 '상(phase)'의 MOSFET을 위상차를 두고 번갈아 켜고 끈다. 각 상의 초크(인덕터)가 에너지를 저장·방출하고 출력 커패시터가 다듬어, CPU가 VID로 디지털 요청한 Vcore를 만든다(고부하 시 대략 1.0~1.4V, 아이들·저전력 상태에서는 0.7V대까지도 내려감). 벅(강압) 컨버터의 출력 전압은 대략 (입력 × 듀티 사이클)로, 스위치가 켜져 있는 시간 비율을 조절해 원하는 전압을 얻는다. 여러 상이 큰 전류(고부하 시 100~200A+)를 나눠 맡아 발열을 분산하고 리플을 서로 상쇄한다.

**8. 부하 추종 · 보호 · (노트북) 배터리·PMIC 경로**

게임·AI 연산으로 부하가 순식간에 치솟거나 꺼지면 컨트롤러가 스위칭 듀티와 활성 상 개수를 즉시 조절해 전압을 유지한다(트랜지언트 대응, 저부하 시엔 상을 꺼 효율을 높이는 phase shedding). 과전류·과전압·저전압·과열·과전력·단락이 감지되면 보호회로가 즉시 차단한다. 노트북에서는 콘센트 대신 리튬이온 배터리가 전원이 되고, 충전 IC가 CC-CV(정전류→정전압) 방식으로 충전을 제어하며, PMIC가 SoC의 각 전압 도메인에 전원을 나눠 주고 DVFS로 필요할 때만 전압·클럭을 올려 배터리를 아낀다.

## 🧩 주요 부품

| 부품 | 하는 일 |
|---|---|
| **EMI/라인 필터 (X·Y 커패시터 + 공통모드 초크)** | PSU가 만드는 고주파 스위칭 노이즈가 전력망으로 새는 것과 외부 서지가 들어오는 것을 양방향으로 차단한다. |
| **NTC 서미스터 / 돌입전류 제한** | 전원을 켜는 순간 벌크 커패시터로 몰리는 돌입 전류를 억제해 퓨즈 단선·부품 손상을 막는다. |
| **브리지 정류기 (다이오드 4개)** | 교류의 음의 반주기를 뒤집어 전류가 한 방향으로만 흐르는 맥동 직류로 바꾼다(전파정류). |
| **벌크 커패시터 (고압 대용량)** | 정류된 맥동 DC의 골을 메워 매끈한 고압 DC로 평활하고, 순간 정전(AC 소실) 시 약 16~20ms 이상 출력을 유지한다(홀드업 타임, ATX 규격 최소 약 16ms). |
| **능동 PFC 회로 (부스트 컨버터 + PFC 초크)** | 입력 전류 파형을 전압 파형에 맞춰 역률을 약 0.99로 올리고, DC 버스를 대략 380~400V로 승압한다. |
| **1차측 스위칭 MOSFET** | 고압 DC를 수십~수백 kHz로 잘게 끊어(스위칭) 변압기에 넣는다. PSU의 핵심 능동소자. |
| **메인 스위칭 트랜스포머** | 전압을 크게 낮추면서 위험한 1차측과 안전한 2차측을 전기적으로 절연한다. |
| **2차측 정류기 / 동기정류 MOSFET + 출력 필터** | 변압기 2차 출력을 다시 정류·평활해 깨끗한 저압 DC 레일을 만든다. |
| **피드백 절연 (옵토커플러 + TL431 기준전압)** | 2차측 출력 전압을 감지해 절연 장벽을 넘어 1차측 컨트롤러로 전달, 부하가 변해도 출력을 규격 안에 유지하게 한다. |
| **DC-DC 컨버터 모듈** | 주 레일 12V에서 +5V·+3.3V를 파생시킨다(현대적 DC-DC 방식). |
| **5VSB 대기 컨버터 (소형 플라이백)** | 콘센트에 꽂혀 있는 한 항상 켜져 전원 버튼·대기 회로·Wake-on-LAN에 전기를 공급한다. |
| **PWM/공진(LLC) 컨트롤러 IC** | 1차측 스위치의 켜고 끄는 타이밍·주파수를 제어하고 피드백으로 전압을 안정화한다. |
| **보호회로 (OCP/OVP/UVP/OTP/OPP/SCP)** | 과전류·과전압·저전압·과열·과전력·단락을 감지해 즉시 출력을 차단, 부품과 사람을 보호한다. |
| **전원 커넥터군 (ATX 24핀 · EPS 8핀 · PCIe/12VHPWR)** | 메인보드·CPU·GPU 등 각 소비처에 정해진 레일을 배분한다. Power Good·PS_ON# 신호선도 여기 포함. |
| **냉각 팬 + 온도센서** | 변환 과정에서 손실로 발생한 열을 밖으로 배출하고, 온도에 따라 팬 속도를 조절한다(저부하 시 정지하는 세미팬리스 설계도 있음). |
| **VRM PWM 컨트롤러** | CPU/GPU의 VID(SVID) 요청을 받아 여러 상의 스위칭을 위상차를 두고 지휘하고, 부하에 맞춰 상을 켜고 끈다. |
| **하이/로우사이드 MOSFET (또는 DrMOS·통합 파워스테이지)** | VRM 각 상에서 12V를 고속으로 스위칭해 강압하는 실제 전력 소자. |
| **초크 (파워 인덕터)** | VRM 각 상에서 스위칭 에너지를 저장·방출하며 출력 전류를 매끈하게 평활한다. |
| **출력 커패시터 (MLCC/폴리머)** | Vcore의 리플과 순간 부하 변동을 흡수해 CPU에 안정적인 전압을 공급한다. |
| **리튬이온/리튬폴리머 셀 (노트북)** | 화학 에너지 형태로 전기를 저장한다. 직렬로 전압을, 병렬로 용량을 키운다(예: 3S2P). |
| **BMS (배터리 관리 시스템)** | 셀 간 전압을 맞추고(밸런싱), 과충·과방전·과열·과전류를 막으며, 쿨롱 카운팅으로 잔량(%)을 계산한다. |
| **충전 IC** | 어댑터 전력을 받아 CC-CV(정전류→정전압) 방식으로 셀을 안전하게 충전한다. |
| **PMIC (전력관리 IC)** | 하나의 입력에서 SoC의 여러 전압 도메인(코어·메모리·I/O 등)을 만들어 분배하고 DVFS로 실시간 조절한다. |
| **입력 퓨즈 (Fuse)** | PSU 입력단의 최종 안전장치. 내부 소자 단락 등 능동 보호회로로도 막지 못하는 치명적 과전류가 발생하면 스스로 녹아 끊겨 회로를 물리적으로 차단, 화재·감전과 전력망으로의 사고 확산을 막는다. 돌입전류를 억제하는 NTC 서미스터, 이상 시 정상적으로 셧다운하는 능동 보호회로(OCP/SCP 등)와 달리, 한 번 끊기면 교체해야 하는 일회성·비복귀형 차단 소자라는 점에서 별개의 핵심 부품이다. |

## 📚 핵심 개념

| 용어 | 설명 |
|---|---|
| **AC / DC (교류 / 직류)** | AC(Alternating Current)는 방향이 주기적으로 바뀌는 콘센트 전기, DC(Direct Current)는 한 방향으로만 흐르는 컴퓨터용 전기. 전원부의 첫 임무가 AC→DC 변환이다. |
| **정류 (Rectification)** | 다이오드로 교류의 음의 반주기를 뒤집어 한 방향(맥동 직류)으로 만드는 것. 브리지(4개)를 쓰면 전파정류. |
| **평활 (Smoothing) / 리플(Ripple)** | 커패시터로 맥동 DC의 출렁임을 메워 매끈하게 만드는 것. 남은 잔물결이 리플이며, 클수록 전원 품질이 나쁘다. |
| **홀드업 타임 (Hold-up time)** | AC 전원이 끊긴 뒤에도 출력이 규격 안에 유지되는 시간. 주로 벌크 커패시터가 담당하며 ATX 규격은 최소 약 16ms(=60Hz 한 주기 16.7ms)를 요구한다. 순간 정전·UPS 전환 대비. |
| **PFC (Power Factor Correction, 역률 개선)** | 입력 전류 파형을 전압 파형에 맞춰 전력망을 효율적으로 쓰게 하는 회로. 능동 PFC는 역률을 약 0.99까지 높인다. |
| **SMPS (Switched-Mode Power Supply, 스위칭 전원)** | 전력을 고주파로 잘게 끊어(스위칭) 변압·조절하는 방식. 선형 방식보다 작고 효율적이라 현대 PSU·VRM의 기본 원리. |
| **절연 (Isolation)** | 변압기로 위험한 1차측(콘센트)과 안전한 2차측(컴퓨터)을 전기적으로 분리하는 것. 출력 피드백은 옵토커플러로 이 장벽을 넘는다. 감전·고장 확산 방지. |
| **레일 (Rail)** | PSU가 공급하는 각 전압 계통. +12V(주력), +5V, +3.3V, +5VSB(대기), 레거시 −12V 등. |
| **Power Good / PWR_OK** | 모든 레일이 규격 안에 안정됐음을 알리는 신호(대략 100~500ms 지연 후 High). 이 신호로 CPU 리셋이 풀린다. |
| **PS_ON#** | 메인보드가 이 신호를 Low로 당기면 PSU가 켜진다(#는 액티브 로우 의미). 전원 버튼과 PSU를 잇는 스위치 신호. |
| **80 PLUS** | PSU 효율 인증. 115V 기준 20/50/100% 부하에서 80% 이상 효율을 요구하며 Bronze~Titanium 등급으로 세분된다(Titanium은 10% 부하점 추가). |
| **VRM (Voltage Regulator Module, 전압 조정 모듈)** | 12V를 CPU/GPU가 요구하는 약 1V로 낮추는 강압 회로. 다상 벅 컨버터로 구성. |
| **벅 컨버터 (Buck, 강압)** | 스위치·인덕터·커패시터로 입력보다 낮은 전압을 만드는 회로. 출력≈입력×듀티사이클. |
| **다상 (Multi-phase)** | 여러 벅 회로(상)를 위상차를 두고 병렬로 돌려 큰 전류를 나눠 맡고 리플을 상쇄하는 기법. |
| **듀티 사이클 (Duty cycle)** | 한 주기 중 스위치가 켜져 있는 시간 비율. 이 비율로 출력 전압을 조절한다. |
| **VID / SVID (Voltage Identification)** | CPU가 필요한 코어 전압을 VRM에 디지털로 요청하는 신호. 과거 VID는 병렬 핀 방식, SVID(및 AMD SVI)는 직렬로 실시간 주고받는 방식. |
| **로드라인 / Vdroop (Load-line)** | 부하가 커질수록 코어 전압을 살짝 낮춰(droop) 순간 스파이크와 과열을 완화하는 의도적 설계. |
| **CC-CV 충전 (정전류-정전압)** | 리튬이온 충전 방식. 처음엔 일정 전류로 빠르게, 만충 근처에선 일정 전압으로 전류를 줄이며 안전하게 채운다. |
| **BMS (Battery Management System)** | 셀 밸런싱·보호·잔량 계산을 담당하는 배터리 두뇌. |
| **PMIC (Power Management IC)** | 하나의 입력에서 SoC의 여러 전압 도메인을 만들어 분배·조절하는 통합 전력관리 칩. |
| **DVFS (Dynamic Voltage and Frequency Scaling)** | 부하에 따라 전압과 클럭을 실시간으로 올리고 내려 성능과 전력소비를 저울질하는 기법. |
| **ATX / EPS12V / 12VHPWR(12V-2x6)** | PSU·메인보드·커넥터 규격. ATX는 폼팩터·24핀, EPS12V는 CPU용 8핀, 12VHPWR/12V-2x6은 ATX 3.0/3.1 GPU용(최대 600W, 4개의 사이드밴드 감지핀으로 공급능력 전달). |
| **USB PD (Power Delivery)** | USB-C로 전압·전류를 협상해 최대 100W(EPR 확장 규격 240W, 48V/5A)까지 공급하는 급속 충전 규격. |
| **쿨롱 카운팅 (Coulomb counting)** | 배터리로 드나든 전하량을 적산해 남은 용량(%)을 추정하는 잔량계(fuel gauge) 방식. |

## ⚠️ 흔한 오해

- **오해** — PSU 정격이 700W면 항상 700W를 소비한다.
  <br>**교정** — 정격은 최대 공급 능력일 뿐, 실제 소비는 부하만큼만 일어난다. 오히려 정격 대비 50% 부근 부하에서 효율이 가장 좋은 경우가 많다.
- **오해** — 80 PLUS 등급이 높으면 전기요금이 크게 줄어든다.
  <br>**교정** — 효율 차이는 대개 수 %p라 절감액은 작다. 더 큰 이점은 낮은 발열과 안정적인 전원 품질, 그리고 인증 제품 특유의 부품 신뢰성이다.
- **오해** — 와트가 크면 무조건 컴퓨터가 빠르고 좋다.
  <br>**교정** — 성능과 무관하다. 과한 용량은 낭비이고, 실제로 중요한 것은 부품 소비전력에 맞는 12V 출력량과 올바른 커넥터·품질이다.
- **오해** — CPU는 12V로 작동한다.
  <br>**교정** — CPU 코어는 약 1V로 작동한다. 12V는 VRM이 받아 강압해 공급하는 것이며, 12V를 코어에 직접 주면 즉시 파손된다.
- **오해** — VRM 상(phase)이 많을수록 항상 좋다.
  <br>**교정** — 상 수는 감당할 전류와 발열 분산을 위한 설계 선택이다. 저부하에선 상이 많으면 오히려 손실이 커서, 실제로는 부하에 따라 상을 껐다 켠다(phase shedding).
- **오해** — 배터리는 항상 100%로 꽉 채워 꽂아두는 게 좋다.
  <br>**교정** — 리튬이온은 항상 만충·고온 상태가 열화를 촉진한다. BMS가 보호하긴 하지만 대략 20~80% 구간을 유지하는 편이 수명에 유리하다.
- **오해** — 배터리는 완전 방전 후 충전해야 한다(메모리 효과).
  <br>**교정** — 메모리 효과는 옛 니켈 계열 배터리 이야기다. 리튬이온엔 메모리 효과가 없고, 오히려 완전 방전은 셀에 해로워 BMS가 그 전에 차단한다.
- **오해** — 충전기 와트가 크면 배터리가 더 상한다.
  <br>**교정** — 충전 IC와 BMS가 셀에 들어가는 전류·전압을 CC-CV로 통제하므로, 규격 내에서라면 어댑터 용량이 커도 셀에 무리하게 밀어넣지 않는다.

## 💡 비유

정수장 비유: 콘센트의 수백 볼트 교류는 불규칙하고 위험한 강물이다. PSU는 정수장이 되어 물을 거르고(정류), 저수지에 받아 수위를 고르고(평활), 압력을 낮춰(변압기) 마실 수 있는 물(12V)로 만든다. VRM은 각 집 수도꼭지 바로 앞의 감압밸브라, CPU가 원하는 딱 1V의 수압으로 마지막 조절을 해 준다. 다상 VRM은 여러 대의 펌프가 번갈아 물을 대 맥동 없이 큰 흐름을 유지하는 것과 같다. 배터리·BMS는 물탱크와 관리인 비유가 어울린다. 셀은 물을 저장하는 여러 칸의 탱크이고, BMS는 각 칸의 수위를 똑같이 맞추고(밸런싱) 넘치거나 마르지 않게 밸브를 잠그는 관리인이다.

## 🔗 CAwiki 시나리오에서 만나는 곳

- 부팅: 전원 버튼을 누르면 메인보드가 PS_ON#을 Low로 당겨 PSU가 켜지고, 모든 레일이 안정되면 Power Good이 떠 CPU의 리셋이 풀리며 첫 명령이 실행된다. 전원부가 주인공이 되는 대표 무대.
- 게임 렌더링: GPU·CPU 부하가 순식간에 치솟아 12V 레일에서 수백 W를 끌어간다. VRM 다상이 위상차로 수백 A를 공급하고, 순간 트랜지언트 스파이크를 출력 커패시터가 흡수한다. ATX 3.0 PSU는 이런 순간 전력 초과(엑스커션)를 견디도록 설계된다.
- 인터넷 검색 왕복 / 영상 스트리밍(노트북): 짧은 연산 뒤 대기가 반복되는 패턴에서 PMIC와 DVFS가 전압·클럭을 낮춰 배터리를 아끼고, 디스플레이·Wi-Fi 전원도 도메인별로 켜고 끈다.
- Ctrl+S 저장 / 파일 열기: SSD가 쓰기·읽기를 하는 순간 전류 스파이크가 발생하고, 갑작스런 정전에도 벌크·출력 커패시터가 약 10~20ms(홀드업 타임)를 버텨 데이터 손상 위험을 줄인다.
- AI 질문: GPU/NPU가 대량 병렬 연산을 시작하면 전력이 급상승한다. VRM과 PSU가 이 순간 부하를 감당하고, 늘어난 발열을 팬이 배출한다.
- 소리 재생: 상대적으로 저부하지만, 3.3V·5V 레일이 오디오 코덱·앰프에 깨끗한 전원을 공급해야 한다. 레일 리플(ATX 상한 +5V/3.3V ≤50mVpp)이 크면 그 잡음이 스피커로 새어 나올 수 있다.
