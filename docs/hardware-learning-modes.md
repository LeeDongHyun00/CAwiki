# 하드웨어 지도 — 학습 단계 UI/UX 개편 (입문·표준·전문가)

작성일 2026-08-27 · 대상: `hardware.html` · `lib/hw-graph.js` · `assets/hardware.css`

## 문제
관계 지도는 첫 화면부터 **21개 노드·115개 관계·부품 322개**를 같은 밀도로 보여준다. 컴퓨터를 처음
배우려는 사람에게는 "무엇부터 봐야 하나"가 없고, 전문가에게는 관계 이유·사양·개념을 한 번에 훑을 수단이 없다.

## 목표
| # | 목표 | 판정 기준 |
|---|---|---|
| G1 | 첫 30초 안에 "컴퓨터는 무엇으로 이루어졌나"를 이해 | 첫 화면에 6개만, 한 문장 정의 |
| G2 | 한 화면에 개념 하나(점진적 공개) | 입문 레슨 = 하드웨어 1 · 부품 3 · 연결 ≤3 |
| G3 | 일상 언어 우선 — 정의 → 비유 → 부품, 전문 용어는 나중 | 비유(`analogy`)가 화면에 등장 |
| G4 | 다음 행동이 항상 명확 | 큰 '다음', 진행도 n/6, 되돌리기 |
| G5 | 숙련자는 밀도를 선택 | 데이터시트 탭·전체 지도·단축키 |
| G6 | 애플풍 모던 — 큰 타이틀·여백·재질·스프링 이징·절제된 색 | 장식 모션 0, 글로우 1개 원칙 유지 |
| G7 | 접근성·모바일 기본 | 세그먼트 role=tablist, aria-live, narrow-stage 유지 |

## 설계
세 **학습 단계**를 세그먼트 컨트롤로 전환하고 `localStorage`에 기억한다. 첫 방문에는 환영 시트가 묻는다.

| 단계 | 무대 | 패널 | 밀도 |
|---|---|---|---|
| **입문** | 핵심 6(CPU·RAM·GPU·SSD·메인보드·전원) 그리드 → 레슨: 중앙 실물 + 함께 일하는 핵심 이웃 ≤3(화살표만) | 한 줄 정의 → 비유 → 부품 3 → 함께 일하는 것 · 다음/이전 | 최소 |
| **표준** | 기존 ego-graph. 관계 글은 호버/포커스에서만 | 역할 + 연관 수 | 중간 |
| **전문가** | ego-graph 전밀도(관계 글 상시) + **전체 지도**(6 클러스터·21노드·115관계, 호버 시 관계 강조) | 탭: 개요·관계·부품·사양·개념 + 단축키 | 최대 |

단축키: `1·2·3` 단계, `M` 전체 지도, `←→` 이웃, `Enter` 이동, `D` 부품 투어, `Esc` 뒤로.

## 모션 원칙(애플풍)
- 이징 `cubic-bezier(.32,.72,0,1)`(스프링 느낌), 세그먼트 썸 슬라이드, 시트 등장(살짝 위→제자리+스케일).
- 등장은 35ms 간격 스태거, 본문 교체는 8px 페이드업 — 모두 '무엇이 바뀌었는지'를 알리는 모션.
- 중앙 실물의 숨쉬기(±2.5%)는 "지금 이것을 보고 있다"는 초점 신호. `prefers-reduced-motion`에서 전부 해제.
- 성능: drop-shadow 글로우는 focus 1개 원칙 유지. 전체 지도 115 라인은 필터 없음.

## 검증
데스크톱·세로 폰에서 세 단계 전환, 레슨 흐름(개요→1..6→완료), 전문가 탭·전체 지도, 콘솔 오류 0.

## 추가 (2026-08-27) — 밀도를 사용자가 조절하는 두 장치

전체 지도와 허브 ego는 정보가 많아 폰에서 노드가 작아진다. **줄여서 크게 보는** 두 장치를 넣었다.

### 1. 전문가 전체 지도 — 카테고리 섬 2단계 줌
카테고리 플레이트를 누르면 그 섬만 확대하고 나머지 섬·노드·관계선은 뒤로 물러난다(dim).
패널은 그 카테고리의 구성원(차수 순)과 **바깥 관계 수**, 다른 카테고리로 건너뛰는 칩으로 바뀐다.
다시 누르거나 `Esc`·'← 전체 지도'로 복귀.

실측(세로 폰 375×812): 배율 **1.0 → 2.4**, 노드 폭 **27.9 → 67px**, 라벨 **5 → 10.5px**.

### 2. 표준 ego — 카테고리 필터 칩
이웃이 `FILTER_MIN`(9) 이상일 때만 무대 하단에 칩 바가 뜬다. `전체` + 카테고리별 개수.
칩을 누르면 그 카테고리만 남고(솔로), 다른 칩을 더 누르면 합집합. 남은 노드가 적어지므로
**카메라가 자동으로 다시 맞춰 노드가 커진다**. 다른 하드웨어로 이동하면 필터는 초기화된다.

실측: CPU(이웃 16) → `메모리` 솔로 시 3개만 표시, `+저장장치` 5개, `전체` 17개 복귀.
