# 시나리오 05–16 — 동작하는 썸네일

기존 01–04와 같은 800×480 장면, 어두운 청록 배경, 금속 기기, 작은 커서와 가는 막대를 사용한다
정지 사진의 확대와 상태 배지는 사용하지 않고 실제 장면 속 요소를 움직인다

| 번호 | 상황 | 동작 직전 | 호버·포커스에서 일어나는 일 |
| --- | --- | --- | --- |
| 05 | 키보드 입력 | 빈 문서와 키 위의 가는 막대 | 막대가 키를 누르고 문서에 글자가 순서대로 나타남 |
| 06 | 프로그램 실행 | 바탕화면 앱 아이콘과 커서 | 두 번 클릭 후 창이 아이콘에서 펼쳐지고 내용이 채워짐 |
| 07 | 문서 저장 | 수정된 문서와 Ctrl·S 키 | 키가 눌리고 저장 진행선 뒤에 체크 표시가 나타남 |
| 08 | 음악 재생 | 멈춘 플레이어와 두 스피커 | 재생 버튼 클릭 후 파형·재생 위치·스피커 진동이 움직임 |
| 09 | 스트리밍 | 일시정지 영상과 짧은 버퍼 | 재생 클릭 후 버퍼가 채워지고 영상과 재생 위치가 이동 |
| 10 | 화상통화 | 웹캠과 연결 전 통화 창 | 참가 클릭 후 카메라 표시등·상대방 타일·마이크 파형 활성화 |
| 11 | 멀티태스킹 | 겹친 문서·브라우저·음악 창 | 뒤쪽 창 선택 후 그 창이 앞으로 나오고 나머지는 뒤로 이동 |
| 12 | USB 연결 | 실제 형태의 플러그와 알루미늄 허브 포트 | 플러그가 포트 안으로 삽입되고 표시등이 켜짐 |
| 13 | 절전 복귀 | 어두운 모니터와 대기 표시등 | 키 누름 후 화면이 켜지고 작업 창이 복원됨 |
| 14 | AI 질문 | 작성된 질문과 전송 버튼 | 전송 후 질문이 대화에 올라가고 생각 표시 뒤에 답변이 순서대로 나타남 |
| 15 | 게임 로딩 | 새 게임 버튼과 배경 | 버튼 클릭 후 로딩 막대가 채워지고 게임 화면·HUD가 나타남 |
| 16 | 화면 녹화 | 바탕화면과 녹화 버튼 | 버튼 클릭 후 빨간 녹화 표시·시간·영상 타임라인이 나타남 |

포인터 진입과 키보드 포커스는 같은 0.2–2.4초의 유한 타임라인을 사용한다
벗어나면 원래 상태로 복귀하고 반복 재생은 하지 않는다
모션 감소 설정에서는 이동·반복 없이 결과 상태를 바로 보여준다
터치는 첫 탭으로 시나리오에 들어가며 모든 카드는 기존 상세 주소를 유지한다

USB 장면은 [실제 기기 사진에 기반한 3D 모델](usb-thumbnail.md)의 렌더 프레임을 사용
