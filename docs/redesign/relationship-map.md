# 하드웨어 관계지도 — 설계와 구현 기준

## 출발점

`main`의 `data/hardware-graph.json`은 하드웨어 21종과 양쪽 관점의 관계 115개를 담고 있다
`lib/wiki.js`의 15개 주제와 `scenarios-and-hardware.md`의 16개 카탈로그를 대조했다
현재 리디자인의 네 편은 그대로 유지하고, USB 연결을 포함한 16개 주제를 관계지도 안에서 모두 탐색할 수 있게 한다

## 화면

- Computer Wiki에 하드웨어·시나리오와 나란히 `관계지도` 진입점을 추가한다
- 첫 화면은 명령과 메모리 / 화면과 그래픽 / 저장과 실행 / 입력과 출력 / 네트워크 / 전원과 냉각의 여섯 묶음
- 묶음을 고르면 주요 부품을 중심에, 함께 작동하는 부품을 주변에 배치한다
- 실물 3D 모델에서 만든 이미지를 사용하고 선택과 이동에만 짧은 전환을 준다
- 부품 선택은 관계 설명을 열고 `이 부품 중심으로`를 누르면 중심을 옮긴다
- 관계는 데이터·제어 / 전원 / 냉각 / 장착·구성 / 활용·비교로 구별한다
- 한 화면에 이웃 여섯 개까지 표시하고 관계 유형 필터와 이전·다음으로 모든 관계에 접근한다
- 검색은 이름과 역할을 대상으로 하며 23개 하드웨어 모두 찾을 수 있다
- 시나리오는 단계별로 관련 부품과 설명을 바꾼다
- 기존 부팅·게임·검색·파일 열기는 해당 3D 시나리오로 이어지는 링크를 둔다

## 의미와 정보 밀도

관계선은 무조건 데이터가 양방향으로 흐르는 물리 배선이라는 뜻이 아니다
각 연결은 A가 B를 필요로 하는 이유와 B가 A에서 맡는 역할을 구분해 설명한다
분류·배치·비교 관계를 실제 데이터 전송처럼 애니메이션하지 않는다
시나리오의 단계 역시 교육용 동작 순서이며 실제 시간 비율을 뜻하지 않는다

21종 원본의 `보조 프로세서`는 현재 단일 칩셋 모델과 같지 않으므로 보조 프로세서 설명에서 칩셋 모델로 잘못 연결하지 않는다
마우스와 VRM을 별도 노드로 보강하며 입력장치·전원 계통과의 포함 관계를 설명한다
기존 연구 데이터의 문서 편집 메모를 사용자 설명에서 제거하고 핵심 설명을 제공한다
제목·문장 끝 마침표, 작은 영어 보조 제목, 푸터 슬로건은 새 화면에도 넣지 않는다

## 구현

`#map`, `#map/group/<id>`, `#map/node/<id>`, `#map/scenario/<id>/<step>`를 사용한다
URL에 선택을 남기고 뒤로 가기로 복원한다
현재 3D 무대는 지도에서 정지시키고 이미지·SVG·HTML로 지도를 구성한다
별도 WebGL 렌더러를 만들지 않아 그래픽 미지원 상태와 모바일에서도 설명·탐색을 유지한다
키보드는 실제 버튼과 링크로 동작하고 모션 감소 설정에서는 전환을 생략한다
독립 HTML에는 관계 데이터도 포함해 오프라인에서 동작하게 한다

## 확인할 것

모든 원본 관계 보존, 추가 두 노드의 참조 무결성, 16개 주제의 전 단계 접근
부품 검색·필터·관계 선택·중심 이동·브라우저 뒤로 가기·3D 시나리오와의 왕복
좁은 화면의 텍스트와 터치 영역, 키보드 선택, 모션 감소, 오프라인, WebGL 미지원

## 데이터 생성과 검증

`python3 tools/build-relation-data.py`는 원본 115개 관계를 보존하고 마우스·VRM의 관계 9개를 추가해 `design/redesign/relation-source.js`를 생성한다
시나리오 16편·64단계는 `design/redesign/relation-scenarios.js`에서 관리한다
`python3 tools/build-redesign-preview.py`로 독립 HTML을 갱신한다

서버 실행 후 `python3 tests/relationship-map.py`로 검색·필터·양쪽 설명·중심 이동·뒤로 가기와 모든 시나리오 단계를 검증했다
모바일 터치·키보드·모션 감소·WebGL 미지원·독립 HTML의 오프라인 탐색도 통과했다
추가 주제는 단계별 관계지도이며 기존 네 편의 3D 필름과 구분한다

## 탐색과 설명의 배치 보완

- 위키와 전체 화면 시나리오 목록에 기존 3D 필름 네 편과 추가 주제 12편을 합쳐 총 16개 카드를 표시한다
- 모바일 시나리오는 현재 단계의 설명을 지도 위에 놓는다 화면을 내려 설명부터 찾아야 하는 동선을 줄인다
- 모바일에서 관계를 선택하면 양쪽 관점 설명으로 이동하며, 지도로 돌아오는 링크를 제공한다
- 검색은 부품 이름·ID의 정확한 일치를 우선하고 설명에 등장하는 관련 부품을 뒤에 놓는다
- 실제 모델 이미지의 사각 배경이 겹쳐 보이지 않게 사이트 바탕색과 합성한다
- 데이터 검증은 원본 모든 관계 보존·전체 부품 묶음 포함·모든 단계의 참조 무결성을 확인한다
- 지도와 기존 3D 무대의 왕복, 상세 팝업 닫힘, 브라우저 뒤로 가기를 실제 WebGL 환경에서 확인한다

## 시나리오 목록 통합

관계지도의 `일상에서 따라가기 / 16가지 작동 원리` 목록은 제거하고 기존 시나리오 카드 목록으로 옮겼다
기존 네 편은 3D 필름으로, 추가 12편은 원래의 단계별 설명으로 연결한다
목록은 중복 없이 01–16으로 번호를 표시하며 위키와 전체 화면 목록에서 동일한 카드 마크업을 사용한다
새 12개 표지는 `assets/scenarios`의 생성 이미지이며 호버와 키보드 포커스에 같은 유한 전환을 적용한다
이전 `#map/scenarios` 주소는 `#stories`로 연결한다
