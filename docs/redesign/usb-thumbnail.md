# USB 시나리오 썸네일

## 사진 참조

- [StarTech USB3SAA3MBK 제품 사진과 데이터시트](https://media.startech.com/cms/pdfs/usb3saa3mbk_datasheet.pdf): 1페이지의 USB-A 플러그 사진에서 금속 셸의 얇은 벽, 두 고정 구멍, 검은 사출 외장, 측면 그립과 케이블 보호 주름을 확인
- [StarTech ST43004UA 제품 사진과 데이터시트](https://media.startech.com/cms/pdfs/st43004ua_datasheet.pdf): 1페이지의 알루미늄 허브 사진에서 둥근 외장 단면, 매립된 포트 테두리와 파란 절연체의 위치·깊이를 확인

제품 사진은 형태 관찰에 사용하며 배포 자산에 포함하지 않음
브랜드 로고 없이 두 개의 포트가 있는 허브와 USB-A 플러그를 직접 모델링

## 목록과의 시각 통일 설계

기존 썸네일의 공통 배경·모니터·창 요소를 사용해 USB 연결 전후의 사용 상황을 구성

| 요소 | 적용 방향 |
| --- | --- |
| 구도 | 모니터를 뒤에 두고 플러그·허브는 앞쪽 낮은 위치에 배치 |
| 배경 | 01–16 공통 청록 방사형 그라디언트를 그대로 노출 |
| 외장 | 먹색·회청록 재질, 낮은 반사, 얇은 모서리 강조 |
| 포트 | 저채도 청록 절연체와 은은한 금속 단자, 실제 깊이·구멍 유지 |
| 투영 | 원근 과장을 줄인 직교 카메라로 기존 일러스트와 유사한 구도 |
| 반응 | 삽입 완료 뒤 모니터 안에 USB 드라이브 행과 민트색 체크 표시 |
| 동작 | 접근·감속·결합·이탈 복귀의 기존 연속 타임라인 유지 |

3D 기기와 그림자만 투명하게 렌더링해 공통 SVG 장면과 합성
별도 상태 배지 없이 컴퓨터 화면과 표시등에서 결과를 보여줌

## 구현

`tools/usb-cover/scene.js`는 Three.js로 작성한 제작용 3D 장면

- 플러그: 구멍이 실제로 뚫린 금속 상·하판, 얇은 측벽, 절연체·금색 접점, 둥근 그립과 이음선·측면 홈, 주름진 케이블 보호부와 굽은 케이블
- 허브: 속이 빈 알루미늄 외장, 실제 포트 개구부, 안쪽 금속 벽과 스프링·절연체·접점, 고무 받침·상태 LED
- 재질: 저채도 회청록 금속, 먹색 플라스틱, 절제된 모서리 반사와 투명한 바닥 그림자
- 삽입: 같은 축과 높이를 유지한 채 접근·감속·결합하며 금속 단자가 포트 안에 실제로 가려진 뒤 표시등 점등

`python3 tools/render-usb-cover.py`로 800×480 투명 프레임 30장을 한 WebP 아틀라스로 렌더링
`--preview`는 시작·종료 렌더만 갱신

`story-usb-preview.js`는 호버·키보드 포커스에 1.25초 타임라인을 실행하고 이탈 시 현재 프레임에서 역순으로 복귀
중간에 다시 진입해도 현재 위치에서 이어지며 완료·이탈 후 애니메이션 루프가 남지 않음
모션 감소 설정은 첫 프레임·마지막 프레임으로 바로 전환
목록에서 추가 WebGL 컨텍스트를 만들지 않으며 독립 HTML에 렌더 이미지를 포함
