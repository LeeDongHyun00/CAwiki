## 구현한 흐름

1–4번의 부팅·게임·검색·파일 열기 24개 장면을 실제 페이지에서 확인하고, 같은 공용 3D 무대와 드래그 방식으로 5–16번을 확장했다
[기존 네 편의 관찰 화면](../../artifacts/scenario-expansion-design/existing-four.jpg)과 [단계 기록](../../artifacts/scenario-expansion-design/reference-audit.json)을 유지한다

추가 시나리오는 최소 6개 장면이라는 기준을 적용해 각 7–9개로 구성했다
12편 총 94개 장면이며 목록에서 바로 3D 필름에 들어간다
관계지도의 기존 설명과도 왕복할 수 있다

- 타이핑 7 — 이미 조합 중인 ㄱ에 ㅏ를 입력해 글자로 그리는 과정
- 앱 실행 8 — 실행 파일·주소 공간·스레드·필요한 페이지·첫 창
- 저장 8 — 쓰기 요청·메모리 대기·장치 명령·전송·기록·동기화·완료
- 음악 7 — 파일·PCM·버퍼·DAC·증폭·진동판
- 스트리밍 8 — 수신·버퍼 부족·회복·디코딩·영상/소리 동기화
- 통화 9 — 카메라·마이크·시간·압축·전송·상대방 버퍼·복원·동기화·결과
- 멀티태스킹 8 — 주소 공간·스케줄링·대기·병렬 실행·교대·복귀
- USB 8 — 연결·초기 통신·주소·장치 정보·드라이버·구성·전송·사용
- 절전 7 — 준비·작업 정리·RAM 유지·전력 감소·깨우기·복구·재개
- AI 8 — 요청·서버·토큰·가중치·모델 연산·다음 토큰·응답 스트림·표시
- 로딩 8 — 요청·읽기·압축 해제·그래픽 준비·VRAM·첫 프레임·추가 읽기·플레이
- 녹화 8 — 캡처·프레임·압축·소리 시간·컨테이너·쓰기·중지·마무리

## 연출

CPU 다이·GPU 처리 영역과 메모리·SSD 컨트롤러와 NAND가 필요한 장면에서 덮개와 라벨을 옆으로 열어 보인다
스피커의 DAC·증폭 회로는 반투명 외장 안의 예시 회로로 설명한다
부품 위의 포인트·색·작업 조각과 같은 공간의 카메라 이동으로 명령, 데이터, 버퍼와 결과를 함께 보여준다
94개 장면의 점검과 변경 의도는 [공간 연출 기록](scenario-spatial-motion.md)을 참조한다
GPU는 기존처럼 메인보드 아래에 둔다
현재 장면을 가리는 주변 장치는 이동 구간에 서서히 사라지고 다음 사용 구간에 들어올 때 다시 나타난다

명령은 빈 고리, 데이터는 면이 있는 조각으로 구별한다
작은 보조 도식은 글자 조합·가상 주소·프로그램별 주소·토큰에만 사용하고, 다른 변화는 부품 위의 색·조각·경로·내부 구조로 표현한다
이를 실제 칩이나 떨어져 나온 부품처럼 그리지 않는다

키캡 눌림, 정밀 USB 플러그 삽입, 스피커 진동판의 미세 움직임은 실제 모델에 적용한다
USB는 사진을 참조해 만든 기존 썸네일의 형상을 공용 무대에서 사용한다
통화는 상대방의 GPU와 화면, AI는 서버의 가속기를 별도 공간에 두어 내 컴퓨터와 구별한다

휠·마우스 드래그·터치 스크롤이 하나의 진행값을 제어한다
단계마다 앞 구간에서 원인을 읽고 뒤 구간에서 다음 부품으로 이동한다
카메라와 도식, 입력 동작, 버퍼, 문서·영상 결과 모두 진행값에서 계산해 역방향에서도 같은 상태를 재현한다
드래그를 놓았을 때 타이머가 다음 장면을 계속 재생하지 않는다

## 설명과 접근

주요 화면에는 단계 번호, 제목, 인과관계 한 문장을 남긴다
상세 설명은 용어의 뜻과 앱·OS·장치별 차이를 설명하고 참고 자료를 연결한다
영문 단계 부제, 상단 내비게이션, 다음 장면 예고 목록은 추가하지 않는다

7–9개 단계에 맞춰 스크롤 길이와 진행 표시가 바뀐다
모바일의 단계 버튼은 44px 조작 영역을 유지하며 선택한 단계가 보이도록 띠 안에서 이동한다
키보드 단계 이동·Home·End·재시작, 상세 팝업의 정지·복귀, 목록과 개별 모델에서 원래 진행 위치로 돌아오는 기능을 유지한다
모션 감소 설정에서는 카메라 이동을 생략하고 대표 상태를 보여준다
WebGL을 사용할 수 없는 경우 부품 이미지와 설명으로 탐색한다

## 코드와 빌드

- `expansion/storyboards.json` — 검토한 제목·설명·상세 원리·장면 의도
- `tools/build-extended-scenarios.py` — 가변 장면 수, 카메라, 연결 경로, 근거 링크를 필름 설정으로 변환
- `scenario-extended-data.js` — 생성된 12편의 설정
- `scenario-film.js` — 기존 공용 렌더러와 스크롤·키보드·팝업·라우팅 동작
- `scenario-mechanisms.js` — 공통 입력 동작과 최상단 보조 도식
- `scenario-signals.js` — 실제 모델 좌표의 포인트·색·작업/데이터 조각·필요한 내부 노출
- `scenario-screen.js` — 드래그로 진행하고 되감는 모니터 속 결과
- `expansion/visuals.json` — 91개 동작 유형의 위치와 연출 의도
- `usb-model.js` — 사진 참조 USB 모델을 렌더러와 분리해 재사용
- `tools/build-pages.py` — 외부 자산 요청 없는 GitHub Pages 배포 파일 생성
