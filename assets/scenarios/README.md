# 이전 시나리오 표지 이미지

추가 시나리오 12편을 위해 ImageGen으로 생성했던 상황 이미지
현재 목록은 `design/redesign/story-actions.js`의 동작하는 SVG 장면으로 교체되었으며 이 사진은 사용하지 않음
외부 사진·브랜드 자산·실제 인물 사진을 사용하지 않음
생성 원본에서 웹용 WebP로 변환했으며 화면에서 5:3으로 표시

| 파일 | 상황 |
| --- | --- |
| typing.webp | 키보드 입력 |
| launch.webp | 바탕화면 앱 실행 |
| save.webp | 문서 저장 |
| music.webp | 음악 재생 |
| streaming.webp | 영상 스트리밍 |
| call.webp | 화상통화 |
| multitasking.webp | 여러 프로그램 실행 |
| usb.webp | USB 연결 |
| sleep.webp | 절전과 복귀 |
| ai.webp | AI 대화 |
| loading.webp | 게임 로딩 |
| record.webp | 화면 녹화 |

공통 방향: 어두운 데스크·흑연색 기기·절제된 청록 조명, 손과 손가락 없는 사용 상황
기존 부팅·게임·검색·파일 열기 표지는 `design/redesign/story-covers.js`의 SVG 장면을 유지
